### **第一阶段：确立Vim宇宙的核心法则 (Mastering the Core Laws)**

**1. 思想转变：从`Ctrl`键到普通模式**

你的敏锐直觉让你意识到Vim的潜力在于“手不离键盘”，但对其“过时”的操作模式感到疑虑。我们确立了第一个核心原则：**用Vim的模式思维，替换掉传统的`Ctrl`组合键思维。**

*   **撤销 (`Ctrl+Z`) → `u` (undo):** 在普通模式下，`u` 成为你的时间机器，可以无限回溯。
*   **重做 (`Ctrl+Y`) → `Ctrl + r` (redo):** 恢复你撤销的操作。
*   **复制 (`Ctrl+C`) → `yy` (yank line):** 在普通模式下，`yy` 复制一整行。`y` 配合移动命令（如 `yw` 复制一个词）进行更精确的复制。
*   **剪切 (`Ctrl+X`) → `dd` (delete line):** 在普通模式下，`dd` 剪切一整行。`d` 配合移动命令进行精确剪切。
*   **粘贴 (`Ctrl+V`) → `p` (paste):** 在普通模式下，`p` 将剪贴板内容粘贴到光标之后。
*   **查找 (`Ctrl+F`) → `/`:** 在普通模式下，按 `/` 进入查找模式，`n` / `N` 在结果中导航。

**结论：** 经过这一阶段，你接受了Vim的模式哲学，并同意将其内化为肌肉记忆。这是你成为“架构师”而非普通“使用者”的第一步。

### **第二阶段：第一个自制武器 (Forging the First Weapon)**

**痛点：** 如何在不退出编辑器的情况下，快速编译和运行C++代码？

**1. 最初的尝试：一个简单粗暴的F5**

我们没有立即引入插件，而是从第一性原理出发，利用Vim的原生能力，在 `init.lua` 中创造了第一个自定义命令。

**演进1 (基础功能):** 我们将“保存、清屏、编译、运行”这一系列shell命令绑定到F5键上。

```lua
-- 这是我们最初的、已被淘汰的F5绑定方式，记录于此作为历史参考
vim.api.nvim_set_keymap('n', '<F5>', ':w !clear && clang++ % -o %< && ./%< <CR>', { noremap = true, silent = true })
```
*   `:w`：解决了你提出的“编译时自动保存”的需求。
*   `%`：代表当前文件名 (e.g., `main.cpp`)。
*   `%<`：代表不含扩展名的文件名 (e.g., `main`)。

**2. 武器的迭代：满足便利性需求**

你提出了一个关键问题：“能不能在插入模式下直接运行？”

这引发了关于Vim哲学的讨论。虽然技术上可行，但我们明确了**“模式分离”**是Vim效率的精髓。尽管如此，为了平滑过渡，我们还是实现了这个功能，并视其为一个“辅助轮”。

```lua
-- 这是为插入模式增加的F5绑定，同样作为历史参考
vim.api.nvim_set_keymap('i', '<F5>', '<ESC>:w !clear && clang++ % -o %< && ./%< <CR>', { noremap = true, silent = true })
```
*   `<ESC>`：在执行命令前，先模拟按下ESC键，自动退回到普通模式。

**结论：** 这一阶段证明了你有能力根据需求定制工具。但我们也看到了原生方法的局限性：体验粗糙，缺乏集成感。这为引入插件系统提供了充分的理由。

#### **一、Vim/Neovim 最小生存技能包**

*   **核心理念：** Vim有多种模式，最常用的是**普通模式(Normal Mode)**和**插入模式(Insert Mode)**。
    *   **普通模式**：默认模式，用于移动、删除、复制等“命令”操作。
    *   **插入模式**：用于打字写代码，和记事本一样。

*   **必备按键：**
    *   `i`：从普通模式进入**插入模式** (Insert)。
    *   `ESC`：从任何模式回到**普通模式** (这是你的“安全键”)。
    *   `:`：在普通模式下，输入“冒号”以进入**命令模式**，用于执行保存、退出等指令。

*   **核心移动 (在普通模式下)：**
    *   `h` (左), `j` (下), `k` (上), `l` (右)

*   **核心编辑 (在普通模式下)：**
    *   `dd`：删除当前行 (并自动复制)。
    *   `yy`：复制当前行 (yank)。
    *   `p`：粘贴 (paste)。

*   **生存指令 (在普通模式下输入)：**
    *   `:w`：保存文件 (write)。
    *   `:q`：退出 (quit)。
    *   `:wq`：保存并退出。
    *   `:q!`：强制退出，不保存任何修改。

*   **最佳入门教程 (强烈建议)：**

-- 一键编译运行 (F5): 使用toggleterm浮动窗口
-- 定义一个名为 "Compiler" 的浮动终端模板
local Terminal = require("toggleterm.terminal").Terminal
local compiler = Terminal:new({
  -- 核心命令: 编译当前文件，然后运行生成的可执行文件
  cmd = "clang++ " .. vim.fn.expand('%') .. " -o " .. vim.fn.expand('%:r') .. " && ./" .. vim.fn.expand('%:r'),
  dir = "git_dir",
  direction = "float",        -- 让它以浮动窗口形式出现
  close_on_exit = false,      -- 运行结束后不自动关闭，方便查看结果和报错
  on_open = function(term)
    vim.cmd("startinsert!") -- 打开时自动进入插入模式（在终端里）
  end,
})

-- 创建一个全局函数来执行编译和运行
function _G.CompileAndRun()
  vim.cmd("w") -- 第一步：自动保存当前文件
  compiler:toggle() -- 第二步：打开或关闭上面定义的 "Compiler" 终端
end

-- 将 F11 键绑定到我们的新函数上
vim.keymap.set("n", "<F11>", "<cmd>lua _G.CompileAndRun()<CR>", {
  noremap = true,
  silent = true,
  desc = "Compile and run current file"
})
