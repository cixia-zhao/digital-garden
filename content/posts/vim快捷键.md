
### **Vim 的哲学：像搭乐高一样组合命令**

在 Normal 模式下，Vim 的操作遵循一个简单的“语法”：**`[动作] + [范围/对象]`**。

*   **动作 (Action)**: 比如 `d` (delete), `y` (yank/copy), `c` (change)。
*   **范围/对象 (Motion)**: 比如 `w` (word), `s` (sentence), `p` (paragraph)，或者你光标移动到的任何地方。

一旦你理解了这个“语法”，你就能组合出无穷的命令，而不需要死记硬背。

### **为你定制的“日常编码”核心命令集**

我们将这些命令分为几个核心场景，请在写代码时有意识地去使用它们，很快就能形成肌肉记忆。

#### **场景一：移动与导航 (Navigation)**

这是所有操作的基础。

*   `h`, `j`, `k`, `l`: 左、下、上、右。这是基础，但更高效的是下面的。
*   `w`: **W**ord - 向前跳一个单词。
*   `b`: **B**ackward - 向后跳一个单词。
*   `0`: 跳到**行首**。
*   `$`: 跳到**行尾**。
*   `gg`: 跳到文件**顶部**。
*   `G`: 跳到文件**底部**。

#### **场景二：删除与修改 (Deletion & Modification)**

这是最常用的编辑操作。

*   `x`: 删除光标下的单个字符 (像剪刀一样剪掉)。
*   `dd`: **D**elete **D**elete - 删除**一整行**。这是 Vim 的经典操作。
*   `dw`: **D**elete **W**ord - 删除一个单词 (从光标处到词尾)。
*   `d$`: **D**elete to End of Line - 删除从光标到行尾的所有内容。
*   `i`: **I**nsert - 在光标**前**进入“插入模式”，开始打字。
*   `a`: **A**ppend - 在光标**后**进入“插入模式”，开始打字。
*   `o`: **O**pen - 在当前行的**下方**打开一个新行，并进入“插入模式”。
*   `O`: (大写O) 在当前行的**上方**打开一个新行，并进入“插入模式”。

#### **场景三：复制与粘贴 (Copy & Paste) - 你的核心需求**

Vim 把“复制”称为 "Yank" (拉取)。

*   `yy`: **Y**ank **Y**ank - 复制**一整行**。
*   `p`: **P**aste - 在光标**之后**粘贴。
*   `P`: (大写P) 在光标**之前**粘贴。

**如何复制局部文本？** 这需要引入 **Visual (可视) 模式**。

1.  将光标移动到你想复制的文本的开头。
2.  按下 `v` 进入**可视模式**。
3.  用移动命令 (`h,j,k,l,w,b,$` 等) 来扩展你的选区。
4.  选好后，按下 `y` (Yank) 来复制选中的文本。
5.  移动光标到你想粘贴的地方，按下 `p`。

**工作流示例：复制 `a + b`**
1.  光标移动到 `a`。
2.  按 `v`。
3.  按两次 `w` (选中 `a + b`)。
4.  按 `y`。
5.  移动到别处，按 `p`。

#### **场景四：撤销与重做 (Undo & Redo) - 你的“后悔药”**

*   `u`: **U**ndo - 撤销上一步操作。你可以连续按 `u` 来不断撤销。
*   `Ctrl + r`: **R**edo - 重做被撤销的操作。

### **为你定制的“高阶编码”核心命令集**

#### **场景一：“语法”的进化：更精准的“范围/对象” (Text Objects)**

你已经知道 `dw` (删除一个单词)，但如果你在单词中间，`dw` 只会删除一半。如果你想**无论光标在哪，都操作整个单词/引号内的内容**，你需要“文本对象 (Text Objects)”。

文本对象由 `i` (inner) 和 `a` (around) 两个前缀和 `w`, `s`, `p`, `(`, `)`, `{`, `}`, `[`, `]`, `"`, `'`, `` ` `` 等符号组成。

*   `i` (inner): 指**内部**内容，不包括两侧的包裹符号（如括号、引号）。
*   `a` (around): 指**整个**对象，包括两侧的包裹符号。

| 动作 | 范围/对象 (Text Object) | 完整命令 | 解释 (假设光标在括号/引号内任意位置) |
| :--- | :--- | :--- | :--- |
| `d` | `iw` | `diw` | **D**elete **I**nner **W**ord - 删除光标所在的**整个单词** |
| `c` | `i"` | `ci"` | **C**hange **I**nner **"** - 删除双引号内的所有内容，并进入插入模式 |
| `y` | `i(` 或 `i)` | `yi(` | **Y**ank **I**nner **(** - 复制括号内的所有内容 |
| `d` | `a{` 或 `a}` | `da{` | **D**elete **A**round **{** - 删除 ` { ... }` 代码块，包括大括号本身 |
| `c` | `at` | `cat` | **C**hange **A**round **T**ag - (HTML/XML) 修改整个标签，包括内容和标签本身 |

**心智模型**: 把 `diw` 想成 "Delete Inner Word"，把 `ci"` 想成 "Change Inner Quote"。这个组合是 Vim 精髓中的精髓，务必掌握。

**工作流示例：修改函数参数**
假设有代码 `call_function("old_parameter", 123)`，光标在 `"old_parameter"` 的任意位置。
1.  输入 `ci"`。
2.  Vim 会瞬间删除 `"old_parameter"` 中的所有内容，留下 `""`，并将光标置于中间，进入插入模式。
3.  你现在可以直接输入 `"new_parameter"`。

#### **场景二：效率倍增器：重复与宏 (Repeat & Macros)**

*   `.` (点号): **重复上一次的修改操作**。这是 Vim 中最强大的命令之一。
    *   **示例**: 你用 `dd` 删除了一行，移动到另一行，按 `.` 会再次执行 `dd`。你用 `ciw` 修改了一个单词，移动到下一个单词，按 `.` 会再次执行 `ciw` 并进入插入模式。

*   **宏 (Macros)**: 录制一系列操作，然后一键重放。
    1.  `q` + `[一个字母]` (如 `qa`): 开始录制宏，并存到字母 `a` 的寄存器中。
    2.  执行你想要录制的一系列操作。
    3.  `q`: 停止录制。
    4.  `@[字母]` (如 `@a`): 重放宏。
    5.  `@@`: 重放上一次执行的宏。

**工作流示例：给多行代码加上引号**
假设有三行文本：
`apple`
`banana`
`cherry`

1.  光标在 `apple` 行首。
2.  `qa` - 开始录制宏到 `a`。
3.  `I"` + `ESC` - 在行首插入 `"`。(`I` 是在行首插入)
4.  `A"` + `ESC` - 在行尾插入 `"`。(`A` 是在行尾插入)
5.  `j` - 移动到下一行。
6.  `q` - 停止录制。
7.  现在光标在 `banana` 行，按 `@a`，`banana` 会被加上引号，并移动到下一行。
8.  再按 `@@`，`cherry` 也会被处理。
9.  如果有 100 行，你可以输入 `100@a`。

#### **场景三：多重剪贴板：深入寄存器 (Registers)**

你以为 Vim 只有一个剪贴板？不，它有几十个！这就是“寄存器”。

*   默认情况下，`y` 和 `d` 使用的是“无名寄存器” (`""`)。
*   你可以指定要用哪个寄存器 (从 `a` 到 `z`)。
*   语法: `"[寄存器名]` + `[动作]`

*   `"ay`**: 将选中的内容复制 (Yank) 到寄存器 `a` 中。
*   `"ap`**: 将寄存器 `a` 中的内容粘贴 (Paste) 出来。
*   `"ad`**: 将删除的内容存入寄存器 `a` (而不是覆盖默认的剪贴板)。

**特殊寄存器**:
*   `"+`**: **系统剪贴板**。这是与外部应用 (如浏览器) 交互的关键。
    *   `"+y`**: 复制到系统剪贴板 (相当于 `Ctrl+C`)。
    *   `"+p`**: 从系统剪贴板粘贴 (相当于 `Ctrl+V`)。
*   `"0`**: **最近一次复制 (Yank) 的内容**。`d` 操作不会影响它。
    *   场景：你先 `yy` 复制了一行，然后 `dd` 删除了另一行。此时按 `p` 会粘贴被删除的行。但如果你按 `"0p`，则会粘贴你最初 `yy` 的那一行。

#### **场景四：批量编辑的艺术：可视块模式 (Visual Block Mode)**

你已经会用 `v` (字符可视模式)。现在认识它的兄弟们：

*   `V` (大写): **行可视模式**。直接选中整行，用 `j`, `k` 扩大选区。
*   `Ctrl + v`: **块可视模式**。这是真正的神器，可以选择一个矩形块。

**工作流示例：给多行代码添加注释**
假设有多行 Python 代码，你想同时注释掉它们：
`line_one = 1`
`line_two = 2`
`line_three = 3`

1.  光标移动到 `line_one` 的行首。
2.  按 `Ctrl + v` 进入块模式。
3.  按 `jj` (或 `2j`) 向下选中三行的行首。
4.  按 `I` (大写i, Insert at the beginning of the selection)。
5.  输入 `# ` (井号和空格)。
6.  按 `ESC`。你会看到 `# ` 被同时添加到了每一行的行首。
