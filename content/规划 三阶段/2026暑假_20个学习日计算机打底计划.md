# 2026暑假第一阶段：20个学习日计算机打底计划

> 适用对象：机械专业跨考计算机；已有C++/STL和算法题经验，但C语言指针、结构体、动态内存、链表及底层数据结构实现不稳定。
> 口径：20个“实际学习日”，不要求连续。打工、家庭事务或外出当天不计入学习日，下一次从未完成的Day继续。

## 一、阶段定位与完成标准

本阶段的目标不是完成正式408第一轮，而是从“会调用STL”转成“能用C语言理解并手写基础数据结构”。暑假结束时，应能独立实现：指针与结构体基础、动态内存、顺序表、单链表、栈、循环队列、五种排序、顺序/二分查找、二叉树基础遍历。图、堆、BST删除等不设为硬目标。

## 二、资料与工具
- 主线C语言：翁恺《C语言程序设计进阶》，只取指针与字符串、结构类型、动态内存相关内容。
- 主线数据结构：王卓《数据结构与算法基础》，按章节选看绪论、线性表、栈和队列、查找、排序、树与二叉树。
- 练习与第二解释：陈越/何钦铭《数据结构》及拼题A公开题目集。陈越不再完整跟一遍，只做对应短视频和题。
- 可视化补充：蓝不过海呀，仅在链表指针变化、树遍历、排序过程无法形成画面时使用。
- 代码环境：阿里云code-server。核心实现使用C语言，不使用STL；陈越综合题可按需要用C或C++，但不能用容器绕过当天训练目标。

## 三、每天的标准时间结构（计算机约3小时）
- 10分钟：闭卷复述昨天的结构和关键接口。
- 40-50分钟：课程/教材，只看当天主题。
- 80-90分钟：从空文件独立编码、编译和测试。
- 30-40分钟：陈越/拼题A题或综合应用。
- 10分钟：记录错因和第二天首先要复现的代码。

低状态最低版：20分钟精准看课 + 60分钟独立代码 + 10分钟记录。最低版不能连续使用两天。

## 四、20个学习日

### Day 1｜指针基础：地址、解引用与函数传参

**目标：** 把“指针是地址变量”落实到可画、可解释、可运行的代码中。

**课程范围：**
- 翁恺《C语言程序设计进阶》：指针的使用、指针运算。
- 只看与指针直接相关的部分；图形库、课程故事线暂时跳过。

**独立代码产出：**
- 写 swap(int *a, int *b)，说明为什么传值不能交换主函数变量。
- 分别用下标与指针遍历整型数组，完成求和、最大值、原地反转。
- 画出主函数变量、指针变量、函数形参之间的地址关系图。

**陈越/拼题A练习：**
- 陈越“起步能力自测题”中任选1道基础编程题，用来熟悉拼题A提交；题目本身不必追求难度。

**完成标准：**
- 从空文件写出指针版 swap 和数组反转。
- 能准确回答：p、*p、&p、&a[i]分别是什么。
- 测试空数组不作为本日要求，但必须测试长度1、长度2和普通数组。

**防偏提醒：** 不要把C++引用与C指针混在一起；今天核心代码只用C语言。

### Day 2｜数组、字符串与指针运算

**目标：** 理解数组名、指针移动和字符数组，不依赖 std::string。

**课程范围：**
- 翁恺：指针运算、字符串操作、字符串函数实现。

**独立代码产出：**
- 手写 my_strlen、my_strcpy、my_strcmp，禁止调用同名库函数。
- 完成字符串反转、统计字符频次、删除指定字符。
- 比较 char a[]="abc" 与 char *p="abc" 的可修改性和存储含义。

**陈越/拼题A练习：**
- 自选1道只涉及字符数组的基础题；若拼题A当前题集不便访问，可用洛谷简单字符串题，但禁止 std::string。

**完成标准：**
- 能够用指针版本独立写出 my_strlen。
- 能解释字符串结尾的 \0，以及越界为什么危险。
- 编译时开启警告，不能留下明显的有符号/无符号或数组越界警告。

**防偏提醒：** 不要为了“写得像C++”封装类；目标是理解内存中的连续字符。

### Day 3｜结构体、typedef、枚举与结构体指针

**目标：** 能把多个字段组织成结点，为链表做准备。

**课程范围：**
- 翁恺：结构类型中的枚举、结构、联合。
- 联合只理解概念，不要求深入练习。

**独立代码产出：**
- 定义 Student 结构体，完成录入、输出、按分数排序、按学号查找。
- 用 typedef 定义类型别名；分别练习变量访问 . 与指针访问 ->。
- 定义枚举表示操作状态或菜单命令，并在程序中实际使用。

**陈越/拼题A练习：**
- 做1道结构体数组题，重点是输入、排序和查找，不追求算法难度。

**完成标准：**
- 能独立写出 typedef struct Student {...} Student;。
- 能解释结构体变量与结构体指针的内存和访问方式。
- 不使用 vector、map、pair。

**防偏提醒：** 不要只会照着模板定义结构体；必须独立设计字段和函数接口。

### Day 4｜动态内存：malloc/free 与二级指针入门

**目标：** 知道内存由谁申请、由谁释放，并能让函数修改外部指针。

**课程范围：**
- 针对性学习 malloc、calloc、realloc、free；优先使用翁恺课程对应片段或配套教材动态内存章节。
- 二级指针只学习“修改指针本身”和“动态创建结点”所需部分。

**独立代码产出：**
- 动态申请 n 个整数，支持扩容、输入、输出和释放。
- 写 create_int(int **p) 或类似函数，让函数内部申请的地址返回给调用者。
- 故意制造一次泄漏、一次 use-after-free，再用 AddressSanitizer 观察报错，随后修复。

**陈越/拼题A练习：**
- 不安排额外算法题；把时间用在内存错误测试。

**完成标准：**
- 每一次 malloc/calloc/realloc 都检查返回值。
- 每一块动态内存只有一个明确释放位置。
- 能解释为什么“释放后继续访问”与“重复释放”都错误。

**防偏提醒：** 今天不追求链表进度。动态内存没弄清，后面链表只会变成背代码。

### Day 5｜算法复杂度与顺序表

**目标：** 建立数据结构课程的入口，并实现第一个抽象数据类型。

**课程范围：**
- 王卓：绪论中算法与算法分析，只看时间复杂度、空间复杂度和数量级。
- 王卓：线性表定义、顺序表示与实现。
- 陈越：线性表及顺序存储的短视频可作为第二解释。

**独立代码产出：**
- 实现 SeqList：初始化、销毁、插入、删除、按值查找、按位访问、打印。
- 插入和删除必须处理非法位置、满表、空表。
- 给每个操作标注时间复杂度。

**陈越/拼题A练习：**
- 陈越“最大子列和问题”作为可选题：只要求理解从暴力到更优算法的复杂度差异，不要求当天一定AC。

**完成标准：**
- 从空文件写出顺序表核心接口。
- 能说明为什么中间插入/删除通常是O(n)。
- 测试空表、满表、首位、末位和非法下标。

**防偏提醒：** 不要因为你熟悉 vector 就跳过顺序表；今天练的是容量、长度和边界管理。

### Day 6｜单链表（一）：结点、创建、遍历与释放

**目标：** 首次完整打通“结构体指针 + 动态内存”。

**课程范围：**
- 王卓：链式存储、单链表定义、初始化、头插法、尾插法。
- 指针变化看不清时，才看蓝不过海呀对应链表动画。

**独立代码产出：**
- 定义结点结构，分别实现带头结点与不带头结点的最小版本。
- 实现头插建表、尾插建表、遍历、求长度、按值查找、整表释放。
- 每次修改指针前，在纸上画 current、next、head 的指向。

**陈越/拼题A练习：**
- 暂不做综合题；用自建测试数据验证0、1、5个结点。

**完成标准：**
- 从空文件完成一种单链表的创建、遍历和释放。
- 释放后主指针置NULL。
- 能解释头结点为什么不存普通数据，以及它带来的统一性。

**防偏提醒：** 禁止复制上一份链表模板；允许看接口清单，不允许看实现。

### Day 7｜单链表（二）：插入、删除、合并与反转

**目标：** 把链表从“能看懂”推进到“能独立改指针”。

**课程范围：**
- 王卓：单链表基本操作与典型应用。
- 陈越：链式存储的插入和删除。

**独立代码产出：**
- 实现按位插入、按值删除、删除指定位置、查找前驱。
- 实现迭代反转单链表。
- 实现两个有序链表的合并，明确是否复用原结点。

**陈越/拼题A练习：**
- 必做：拼题A“两个有序链表序列的合并”（若当前题集名称略有变化，选同类型函数题）。

**完成标准：**
- 能在纸上完整画出删除中间结点和反转前三步。
- 空链表、单结点、删除头部、删除尾部均测试。
- 说明合并算法的时间复杂度。

**防偏提醒：** 链表出错先画图，禁止让AI直接重写整份代码。

### Day 8｜链表闭卷巩固与综合应用

**目标：** 验证前两天是否只是短期记忆。

**课程范围：**
- 只在暴露具体问题后回看相应片段，不再顺序听课。

**独立代码产出：**
- 闭卷重写：创建、插入、删除、反转、释放。
- 任选一个扩展：删除所有重复值、找中间结点、倒数第k个结点、判断是否有环。

**陈越/拼题A练习：**
- 挑战题：拼题A“Reversing Linked List”。若30分钟仍无法建模，先写自然语言步骤，再看题解思路，最后关掉题解独立重写。

**完成标准：**
- 核心链表接口不看旧代码可以完成。
- 至少完成1个扩展操作。
- 错因记录必须具体到“哪个指针、哪个边界、为何丢链”。

**防偏提醒：** Reversing Linked List不是本阶段硬性AC指标，链表基本操作闭卷完成才是。

### Day 9｜栈：顺序栈、链栈与括号匹配

**目标：** 理解受限线性表，而不是只会 stack<int>。

**课程范围：**

**陈越/拼题A练习：**

### Day 10｜队列：循环队列与链队列

**目标：** 彻底理解 front/rear 和队空、队满判定。

**课程范围：**
- 王卓：队列的顺序表示、循环队列、链队列。

**独立代码产出：**

**陈越/拼题A练习：**

**完成标准：**
- 能独立写出循环队列入队、出队公式。

- 能解释两种判满方案。

**防偏提醒：** rear指向“最后元素”还是“下一可用位置”必须在代码开头写清楚，不能混用。

### Day 11｜递归与线性结构综合

- 从栈或队列中选一个，闭卷重写。
- 完成一道综合小题：栈实现进制转换、队列模拟或简单表达式括号检查。

**陈越/拼题A练习：**
- 不安排高难新题；把此前未AC的栈/队列题完成。

**完成标准：**

- 能手画3层调用栈。
- 线性表、链表、栈、队列至少三项达到“闭卷可写”。

**防偏提醒：** 不要用递归解决所有问题；先判断是否存在清晰的子问题。

### Day 12｜基础排序：冒泡、选择、插入

**目标：** 不仅会写，还要能解释一趟发生了什么。

**课程范围：**

**独立代码产出：**
- 独立实现冒泡、选择、直接插入排序。
- 为每个算法输出每一趟后的数组，用小数据手工核验。
- 记录比较次数和移动/交换次数。

**陈越/拼题A练习：**
- 从“浙大版《数据结构（第2版）》题目集”选1道基础排序函数题。

**完成标准：**
- 三种排序从空文件写出。
- 能解释稳定性，不只背结论。
- 能说出最好/最坏情况下冒泡和插入排序为何不同。

**防偏提醒：** 不要追求模板最短；变量名和循环边界必须可解释。

### Day 13｜快速排序：划分思想与边界

**目标：** 掌握分治和partition，不把快排当背诵模板。

**课程范围：**
- 王卓：快速排序。
- 看懂一种划分法即可，暂不混学多个模板。

**独立代码产出：**
- 实现一种固定的partition方案，并在注释中写清区间是[l,r]还是[l,r)。
- 测试升序、降序、全相等、大量重复值、长度0/1。
- 输出递归区间，观察最坏情况。

**陈越/拼题A练习：**
- 做1道要求使用或判断快速排序过程的题；若拼题A没有合适题，可自写“输出每次划分结果”的测试。

**完成标准：**
- 闭卷写出快排。
- 能解释平均O(n log n)和最坏O(n²)的来源。
- 重复值数据不会死循环。

**防偏提醒：** 今天只固定一种正确模板，禁止同时抄三种partition写法。

### Day 14｜归并排序：合并两个有序区间

### Day 15｜查找与排序收口：顺序查找、二分查找

**目标：** 掌握二分边界，并完成五种排序的闭卷复写。

**课程范围：**
- 王卓：顺序查找、折半查找。

**独立代码产出：**

**陈越/拼题A练习：**
- 必做：拼题A公开题目集中的“二分查找”函数题或同类题。

**完成标准：**

### Day 16｜二叉树（一）：结点、递归遍历与建树

**目标：** 把链式结构扩展到树，理解递归遍历。

**独立代码产出：**

- 用手动连接或先序序列（空结点标记）建树。
- 实现先序、中序、后序递归遍历。

**陈越/拼题A练习：**
- 拼题A函数题“先序输出叶结点”可作为当天练习。

**完成标准：**
- 三种遍历不看代码写出。
- 能根据一棵小树手算遍历结果。
- 整棵树能递归释放。

**防偏提醒：** 不要只背三段几乎相同的代码；要说清“访问根结点”发生在哪一步。

### Day 17｜二叉树（二）：层序遍历、结点数与高度

**目标：** 把自写队列用于树，并掌握常见递归统计。

**课程范围：**

**独立代码产出：**

**陈越/拼题A练习：**
- 选做“树的同构”或相近的树结构判断题；当天核心是层序和统计函数。

**完成标准：**

**防偏提醒：** 递归函数先定义“它返回什么”，再写左右子树组合，避免边写边猜。

### Day 18｜二叉树闭卷巩固与BST入门

**陈越/拼题A练习：**

## 五、统一执行规则
- 核心实现一律从空文件开始；允许看接口清单，不允许先复制实现。
- 核心结构优先使用C语言和gcc；若某道陈越题用C++，不得使用STL容器替代正在学习的数据结构。
- 每个程序至少测试：正常输入、空结构或长度0、单元素、边界位置、重复值（适用时）。
- 建议编译参数：gcc -std=c11 -Wall -Wextra -Wpedantic -g -fsanitize=address,undefined。
- AI只可解释报错、检查已写代码、生成测试数据、追问思路；禁止先生成完整实现。
- 某项当天未完成：第二天前30分钟再写一次；仍不会则进入Day19补漏，不允许无限顺延整张计划。
- 每个模块保留first_try.c、final.c和README.md。README只写：我错在哪里、边界是什么、下次如何避免。
- 不继续改造服务器、不新增AI项目、不折腾笔记系统。环境已经足够。

## 六、暑假结束后的合格线
- A级（独立）：单链表、循环队列、至少一种O(n log n)排序、三种递归遍历。
- B级（小提示后可完成）：顺序表、栈、其余排序、二分查找、层序遍历和树高。
- 概念清楚：指针/地址/解引用、结构体指针、malloc/free、复杂度、稳定性、递归终止条件。
- 不要求：完整408考点、图论、AVL/B树、线索树、所有排序、408真题。

## 七、依据与适用边界

计划吸收了用户整理材料中“数据结构必须落实到手写代码、先自然语言再翻译为代码、王卓适合系统基础、陈越适合实现与练习”的部分；但20天安排是根据用户当前基础和80小时左右的暑假总量重新设计，不是任何单一博主的原计划。
