# 三、一战完整时间线

## 1. 2024年3—4月：买课准备开始，但被实习拖住

作者按照应届考研时间线，认为自己本应在2024年3—4月开始准备，也确实在此时购买课程、准备学习。[P01]

但当时正值大三下，学院要求进行一个学期、约六个月的实习。作者描述：

- 实习上班本来已经很疲惫。
- 仍设想晚上回家学一会、周末再补。
- 实际学习效果不好。
- 最终用“暑假实习结束，回学校才有状态”作为推迟计划的理由。[P01]

作者事后认为，假如能在实习期间坚持一点，把基础阶段推进得差不多，后面会轻松很多。[P01]

### 作者明确指出的错误

不是实习本身不可克服，而是不断给延后开始寻找合理理由。

---

## 2. 2024年7月初：回学校后因身体不适再次中断

暑假7月初，作者回到学校，但肠胃持续不适。几天后因为难受回家，同时也受到以下因素影响：

- 实习半年后想家。
- 暑假学校人少、环境冷清。
- 仍幻想回家后可以继续学习。[P02]

回家后：

- 身体每天不舒服。
- 肠胃炎持续较久。
- 没有形成每天学习的习惯。
- 学习计划继续被推迟到开学。[P02]

作者把这段经历称为自己的**第一个大弯路**，核心是“一直拖着不开始”，结果错过了暑假这一段宝贵时间。[P02]

### 证据边界

身体不适是真实影响因素，不能简单归结为懒惰；但作者本人强调，身体原因之外，还存在反复推迟、环境依赖和没有建立习惯的问题。

## 3. 2024年8月底：正式回校，但每日学习时间受环境限制

8月底，作者终于回学校开始学习。[P02]

当时：

- 图书馆每天下午5点左右关门。
- 作者便顺势每天学到5点结束。[P02]

进入9月后：

### 合理概括

作者不是从3—4月持续备考到年底，而是经历了多次启动失败；较稳定的学习实际上到8月底、9月才开始。

## 4. 2024年9月：进度焦虑导致只看课、不做题

进入9月后，作者因进度焦虑做出关键错误：

- 直接取消数学做题环节。
- 开始“框框往后刷课”。
- 他事后认为，时间紧张时更好的策略应是：
  - 看课本；
  - 不大量听课；
  - 同时坚持做题。[P03]

作者用约一个月时间完成：

- 数学基础阶段所有课程。
- 408基础阶段所有课程。[P03]

随后在10月开始强化。

### 作者明确指出的第二个大弯路

因为害怕进度慢，把“做完课程”当成了“完成学习”，数学只刷课、不写题。

### 关键证据

作者并未说基础阶段完全没学习，而是明确说：

- 课程进度推进很快；
- 但写题环节被放弃；
- 结果基础没有通过题目真正落实。[P03]

# 五、作者明确总结的一战失败原因

作者在结尾把一战失败概括为以下几类问题。[P05-P06]

## 1. 开始时间太晚

作者认为自己本应在暑假开始稳定学习，但实际一直拖延到8月底甚至9月才形成较稳定节奏。[P02][P06]

导致延迟的因素包括：

- 六个月实习带来的疲惫。
- 想等实习结束再开始。
- 身体不适。
- 回家后环境和习惯不利。
- 一再把计划推迟到下一个时间点。[P01-P02]

## 2. 数学只听课、不做题

这是作者反复强调的核心失误：

- 基础阶段不做题。
- 强化阶段仍不做题。
- 通过课程进度制造“学完了”的错觉。
- 没有用做题检验和巩固理解。[P03][P06]

## 3. 过度相信少量真题成绩

作者做一套较简单的数学真题满分，又做几套均分约120，便认为数学已稳。[P03-P04]

由此产生：

- 一周不学数学。
- 提前转移主线。
- 没有继续查漏补缺。
- 把偶然表现当成真实水平。[P03-P04]

## 4. 英语准备不完整

作者概括的一战英语问题包括：

- 暑假背单词，但没有坚持。
- 阅读真题做得少。
- 没有系统研究阅读问题。
- 作文策略选择失误。[P04-P06]

## 5. 进度焦虑导致错误决策

作者不是单纯因为时间不足失败，而是在时间不足时“慌不择路”：

- 为了赶进度删除做题环节。
- 用刷课代替掌握。
- 做少量试卷后又过早乐观。
- 在科目之间大幅度切换。[P03-P05]

# 十一、可迁移的反面经验

以下结论直接来自作者的一战复盘，而不是模型补充的一般经验。

## 1. 不要把“计划开始”当成“已经开始”

作者3—4月买了课程，却因实习、暑假、身体和环境反复推迟，直到8月底才真正进入学习。[P01-P02]

## 2. 时间紧张时，不能首先删除做题

作者为了赶进度取消数学做题，基础和强化阶段都只看课，最终把课程完成度误当成掌握程度。[P03]

## 3. 一套或几套卷子的高分不能证明稳定水平

2017年数学满分和几套均分120，让作者停止数学并转移精力；作者后来明确把这种判断视为弯路。[P03-P04]

## 4. 弱项不能因为估分“差不多”就停止处理

英语只做少量真题后，作者认为阅读尚可，便转向其他内容；正式考试却受到英语试题冲击。[P04]

## 5. 临近考试也要做策略选择，而不是慌乱堆任务

作者最后强调：时间不够时不要慌不择路，即使剩余时间很少，也应思考投入产出比最高的策略。[P06]

# 十四、最终结论

这份材料最有价值的地方，不是提供一套可以照抄的备考计划，而是展示了一条典型的失败链条：

1. 暑假没有真正开始。
2. 数学长期不做题。
3. 英语阅读准备不足。
4. 作文策略投入产出比低。

当前材料只能作为“失败避坑证据”，不能据此还原作者的二战成功方案，也不能单独用于制定完整的数学或408计划。
