## 1. 结构作为函数参数与传值机制

### 核心速记

* **结构体可作为独立数据类型**：一旦声明了结构，它就可以像 `int`、`float` 一样作为函数的参数或返回值。
* **本质为值传递（Pass by Value）**：将结构变量传入函数时，系统会在函数内部创建一个新的结构变量，并**完整拷贝**调用者结构体中的所有成员值。
* **与数组传参的区别**：数组传参传递的是首地址，函数内部对数组的修改会直接影响外层；而结构体传参是**内存拷贝**，函数内部对结构的修改默认不影响外层。
* **取地址与成员运算符优先级**：在如 `scanf("%d", &today.month);` 的表达式中，成员访问运算符 `.` 的优先级**高于**取地址运算符 `&`，等价于 `&(today.month)`。

> [!warning]- 结构传参的值传递陷阱与运算符优先级
> 
> **1. 值传递的内存图景**
> 当结构体作为参数传入函数时，C 语言会执行**按字节拷贝**。
> ```c
> struct date {
>     int month;
>     int day;
>     int year;
> };
> 
> // 函数内部的 d 是一个全新的局部变量
> int numberOfDays(struct date d) {
>     // 此处对 d.day 的修改不会影响主调函数中的实参
>     return 0;
> }
> ```
> 
> **2. 运算符优先级辨析（`.` 与 `&`）**
> * 表达式：`&today.month`
> * 常见误区：误以为先对 `today` 取地址，再访问 `month`。
> * 正确逻辑：`.` 优先级高于 `&`，编译器先计算 `today.month` 取得成员变量，再用 `&` 取出该成员在内存中的具体地址交付给 `scanf`。

## 2. 结构体的输入机制与返回值解决方案

### 核心速记

* **无法直接批量输入**：C 语言标准库没有提供一次性读取整个结构的格式化占位符，必须对成员逐个调用 `scanf`。
* **“传值输入”的失效原因**：编写 `void getStruct(struct point p)` 在内部 `scanf` 无法将数据写回实参，因为 `p` 仅是外层变量的副本，离开作用域后副本即被销毁。
* **解决方案：通过函数返回结构体**：定义函数返回类型为结构体 `struct point getStruct(void)`，在内部创建临时结构变量，读取完成后通过 `return p;` 将整个结构体拷贝回外层。

> [!note]- 值传递导致的“无效输入”与结构返回机制
> 
> **1. 错误实现：传值试图修改外层变量**
> ```c
> // 错误示例：形参 p 只是外层变量 y 的克隆体
> void getStruct(struct point p) {
>     scanf("%d", &p.x);
>     scanf("%d", &p.y);
> }
> 
> int main(void) {
>     struct point y = {0, 0};
>     getStruct(y); // 离开函数后，y 依然是 {0, 0}！
> }
> ```
> 
> **2. 正确实现：利用返回值进行结构体拷贝**
> ```c
> // 正确示例：无参，返回结构体类型
> struct point getStruct(void) {
>     struct point p; // 临时本地变量
>     scanf("%d", &p.x);
>     scanf("%d", &p.y);
>     return p;       // 离开函数时，p 的值会被完整拷贝给调用者
> }
> 
> int main(void) {
>     struct point y = {0, 0};
>     y = getStruct(); // 利用结构体间的直接赋值完成更新
> }
> ```
> 
> **底层原理：**
> C 语言支持同类型结构体之间的直接赋值（如 `y = p;`）。虽然局部变量 `p` 在函数返回后生命周期结束，但 `return` 会将 `p` 的值复制一份写回调用者的接收变量 `y` 中。

## 3. 结构指针与 `->` 运算符（高性能最佳实践）

### 核心速记

* **K&R 性能金科玉律**：当结构体体积较大时，向函数传递结构指针比直接传递整个结构体效率高得多（“If a large structure is to be passed to a function, it is generally more efficient to pass a pointer than to copy the whole structure”）。
* **传指针的优势**：结构体按值传递需要复制每个字节，消耗栈空间；而传指针只需要传递固定大小的内存地址（32 位系统为 4 字节，64 位系统为 8 字节）。
* **指向运算符 `->`**：若 `p` 是指向结构体的指针，访问其成员的简洁语法为 `p->member`，等价于 `(*p).member`。
* **括号的必要性**：`*p.member` 会报错，因为 `.` 的优先级高于 `*`，编译器会将其误解析为 `*(p.member)`，因此必须写作 `(*p).member`。
* **只读保护原则**：如果传递指针仅仅是为了读取结构体数据，应该在形参前加上 `const` 关键字（如 `void print(const struct point *p)`），防止函数内部意外修改原数据。

> [!warning]- 结构指针的高级套路与解引用左值陷阱
> 
> **1. 常用工程套路：输入函数返回指针以支持链式调用**
> ```c
> // 传入指针，修改内容，并重新返回该指针
> struct point* getStruct(struct point *p) {
>     scanf("%d", &p->x);
>     scanf("%d", &p->y);
>     return p;
> }
> 
> void print(const struct point *p) {
>     printf("%d, %d\n", p->x, p->y);
> }
> 
> int main(void) {
>     struct point y = {0, 0};
>     // 链式调用：getStruct 返回的指针直接作为 print 的参数
>     print(getStruct(&y)); 
> }
> ```
> 
> **2. C 语言的“黑魔法”：函数返回指针解引用作为左值**
> ```c
> // 解引用函数返回的指针，结果是一个合法的“左值（L-value）”
> *getStruct(&y) = (struct point){1, 2};
> ```
> 
> **语法剖析：**
> `getStruct(&y)` 返回指向 `y` 的指针 `&y`。前面的 `*` 运算符对该指针进行解引用，得到的就是外层变量 `y` 本身。因此赋值号左边并非普通的函数调用，而是代表真实的内存区域，可以被合法赋值。

## 4. 结构数组及其初始化
### 核心速记
 * **结构体的数组化**：结构体与基础数据类型（如 int、float）完全相同，可以声明为数组（如 struct date dates[100];），数组中的每个元素都是一个独立的结构体变量。
 * **嵌套大括号初始化**：初始化结构数组时，最外层大括号代表数组整体，内部每个元素由独立的大括号包裹，依次给结构体的成员赋值（例如：{{4, 5, 2005}, {2, 4, 2005}}）。
 * **自动推导数组长度**：显式提供初始化列表时，方括号内的数组长度可以省略（如 struct date dates[] = ...），编译器会自动根据初始化的元素个数推导数组长度。
 * **成员访问逻辑**：访问结构数组元素的成员时，遵从“先索引后成员”规则，表达式形如 array[i].member。
> [!note]- 结构数组的内存布局与成员访问逻辑
> **1. 内存中的连续排布**
> 结构数组在内存中是连续存放的。如果 struct date 包含 3 个 int（共 12 字节），那么 dates[100] 将在内存中连续占用 1200 字节的存储空间。
> **2. 典型例程：遍历与更新结构数组**
> ```c
> struct time {
>     int hour;
>     int minutes;
>     int seconds;
> };
> 
> // 定义并初始化包含 5 个 time 结构的数组
> struct time testTimes[5] = {
>     {11, 59, 59}, {12, 0, 0}, {1, 29, 59}, {23, 59, 59}, {19, 12, 27}
> };
> 
> for (int i = 0; i < 5; i++) {
>     // 1. 访问成员：先通过 testTimes[i] 锁定元素，再用 . 访问内部成员
>     printf("Time is %02d:%02d:%02d\n", testTimes[i].hour, testTimes[i].minutes, testTimes[i].seconds);
>     
>     // 2. 传参与赋值：将结构体元素作为参数传入，并用返回值更新数组元素
>     testTimes[i] = timeUpdate(testTimes[i]);
> }
> 
> ```

## 5. 结构中的结构（嵌套结构）与成员访问
### 核心速记
 * **结构的复合与组合**：结构体的成员不仅可以是基础数据类型，也可以是另一个已定义的结构体（例如矩形 rectangle 由两个点 point 结构体构成）。
 * **多层级点运算符访问**：访问嵌套结构体内部成员时，需要从外到内逐层使用点运算符 .（例如 r.pt1.x）。
 * **指针访问混用法则**：
   * 若 rp 是指向外层结构的指针，访问嵌套结构成员可写作 rp->pt1.x 或 (*rp).pt1.x。
   * **绝不可误写为 rp->pt1->x**，因为 pt1 是结构体实体而非指针。
> [!warning]- 嵌套结构体指针访问的表达形式与语法禁区
> **1. 嵌套结构体定义示例**
> ```c
> struct point {
>     int x;
>     int y;
> };
> 
> struct rectangle {
>     struct point pt1; // 左上角点
>     struct point pt2; // 右下角点
> };
> 
> ```
> **2. 合法访问形式对比（假设定义 struct rectangle r; struct rectangle *rp = &r;）**
> | 表达形式 | 语法逻辑解析 | 是否合法 |
> |---|---|---|
> | r.pt1.x | 直接通过外层结构变量逐级访问 | 合法 |
> | rp->pt1.x | 指针解引用外层结构，再访问 pt1 的 x | 合法 |
> | (*rp).pt1.x | 显式解引用指针，等价于 r.pt1.x | 合法 |
> | (r.pt1).x | 显式加括号，与 r.pt1.x 严格等价 | 合法 |
> | rp->pt1->x | **语法错误**：pt1 是结构体对象而非指针 | **非法** |
> **3. 核心语法规则总结**
> 只有当运算符左边是**指针**时才能使用 ->；当左边是**结构体变量/对象**时，必须且只能使用 .。

## 6. 结构中的结构的数组（多层嵌套与初始化）
### 核心速记
 * **多重组合机制**：C 语言支持“结构中的结构的数组”（即元素为嵌套结构的数组），展现了类型组合的高度自由性。
 * **多层嵌套大括号排版**：三层初始化的语法层次依次为：最外层 {}（数组） → 中间层 {}（外层结构体） → 最内层 {}（内层嵌套结构体）。
 * **代码可读性对齐规范**：多层嵌套初始化时推荐按行缩进排版，使大括号的层次与数据结构逻辑完全对应，避免遗漏括号或填错字段。
> [!note]- 深度嵌套结构的初始化与内存映射关系
> **1. 代码实现与多层大括号映射**
> ```c
> #include <stdio.h>
> 
> struct point {
>     int x;
>     int y;
> };
> 
> struct rectangle {
>     struct point p1;
>     struct point p2;
> };
> 
> void printRect(struct rectangle r) {
>     printf("<%d,%d> to <%d,%d>\n", r.p1.x, r.p1.y, r.p2.x, r.p2.y);
> }
> 
> int main(void) {
>     // 定义包含 2 个矩形的数组，每个矩形由 2 个 point 构成
>     struct rectangle rects[] = {
>         // 第一层：rects[0] (第一个矩形)
>         { {1, 2}, {3, 4} }, // {p1(x,y), p2(x,y)}
>         // 第二层：rects[1] (第二个矩形)
>         { {5, 6}, {7, 8} }  // {p1(x,y), p2(x,y)}
>     };
> 
>     for (int i = 0; i < 2; i++) {
>         printRect(rects[i]);
>     }
>     return 0;
> }
> 
> ```
> **2. 结构解析**
>  * {1, 2} 初始化 rects[0].p1（其中 x=1, y=2）。
>  * {3, 4} 初始化 rects[0].p2（其中 x=3, y=4）。
>  * 通过规范的多层缩进，可以清晰地区分数组元素与嵌套结构成员，防止初学者出现初始化数值错位。
>
