## 1. size_t 与 int

### 核心速记
* **`size_t`**：**无符号**（`unsigned`），专门用来表示内存大小、数组长度和下标。64 位系统下占 8 字节。
* **`int`**：**有符号**（`signed`），通用整数计数，可正可负。大多数系统下固定占 4 字节。
* **选型原则**：涉及内存分配、数组索引、`sizeof` 返回值**强制用 `size_t`**；涉及负数或逻辑计数用 `int`。

> [!warning]- 模糊点解析：两大常见坑点（点击展开）
> 1. **倒序循环死循环**
>    `size_t` 无法表示负数，`0` 再减 `1` 会下溢变成巨大的正数（例如 $2^{64}-1$）。
>    ```c
>    // ❌ 错误：i >= 0 永远成立，导致死循环
>    for (size_t i = 10; i >= 0; i--) { ... } 
>    ```
> 2. **隐式转换导致比较错误**
>    当 `int` 与 `size_t` 比较时，`int` 会被隐式转换为 `size_t`。
>    ```c
>    int a = -1;
>    size_t b = 5;
>    if (a < b) { ... } // ❌ 结果为假！因为 -1 转为 size_t 会变成极大的正数
>    ```

## 2. 字符串比较 (myCmp / strcmp)

### 核心速记
* **函数功能**：按字典序比较两个字符串，**不是比较字符串长度**。
* **返回值规则**：返回**第一个不相同字符的 ASCII 码差值**（`s1[i] - s2[i]`）。
  * **小于 0**：`s1` 小于 `s2`
  * **等于 0**：两字符串完全相同
  * **大于 0**：`s1` 大于 `s2`

> [!note]- 模糊点解析：原代码逻辑错误与正确实现（点击展开）
> **原代码问题**：原代码返回了相同字符的计数 `idx`，这只能代表“匹配长度”，永远无法输出负数，导致无法判断 `s1 < s2` 的情况。
> 
> **正确手写实现**：
> ```c
> int myCmp(const char* s1, const char* s2)
> {
>     int idx = 0;
>     while (s1[idx] == s2[idx] && s1[idx] != '\0')
>     {
>         idx++;
>     }
>     // 返回当前位置不相等字符的 ASCII 码差值
>     return (unsigned char)s1[idx] - (unsigned char)s2[idx];
> }
> ```

## 3. 字符串拷贝 (mycpy / strcpy)

### 核心速记
* **四大基本原则**：
  1. 必须预先为目标内存分配**足够的空间**（如 `char s3[100]`）。
  2. 循环判断条件是**源字符串 `s2` 是否到达 `'\0'`**。
  3. 拷贝完成后必须**手动补上字符串结束符 `'\0'`**。
  4. 必须**返回目标字符串的首地址**。

> [!note]- 模糊点解析：原代码避坑与手写实现（点击展开）
> **原代码三大坑点**：
> 1. `while(s1 != '\0')`：判断的是 `s1` 指针本身的内存地址，导致死循环或越界。
> 2. 漏掉 `'\0'`：导致拷贝后的字符串末尾出现随机乱码。
> 3. 指针自增后直接 `return s1`：返回的是字符串末尾地址，导致无法打印完整字符串。
> 
> **正确手写实现（指针移位法）**：
> ```c
> char* mycpy(char* dest, const char* src)
> {
>     char* start = dest; // 1. 记下首地址用于返回
>     
>     while (*src != '\0') // 2. 检查源字符
>     {
>         *dest = *src;
>         dest++;
>         src++;
>     }
>     *dest = '\0'; // 3. 补齐结束符
>     
>     return start; // 4. 返回目标首地址
> }
> ```

## 4. char、char[] 与 char* 的本质区别

### 核心速记
* **`char`**：单个字符变量，占 1 字节（如 `'a'`）。
* **`char p[]`（字符数组）**：在栈上真实开辟一片内存空间（“房子”）。**内容可修改**，数组名是常量地址，不可改变指向。
* **`char* p`（字符指针）**：仅开辟一个存地址的变量（“门牌号”）。指针方向**可随意改变**；若指向字符串常量（如 `"hello"`），则**内容不可修改**。

> [!info]- 模糊点解析：为什么形式上感觉一样？（点击展开）
> **1. 语法糖（下标访问）**
> 无论是数组还是指针，都可以用 `p[i]` 的形式访问，因为 C 语言中 `p[i]` 本质上就是 `*(p + i)` 的简写。
> 
> **2. 函数参数退化**
> 在函数声明中，`void func(char p[])` 和 `void func(char *p)` 在编译器眼里**完全等价**。数组作为参数传递时，会自动退化（隐式转换）为指针，因此调用时传数组或传指针均可兼容。
