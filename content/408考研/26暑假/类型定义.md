## C 语言类型定义 (typedef)

### 核心速记
* **基本概念**：`typedef` 是 C 语言用于为已有数据类型声明**别名（Alias）**的关键字。
* **核心作用**：
  * **简化结构体调用**：消除每次定义变量时必须书写 `struct` 关键字的繁琐（如用 `Date` 代替 `struct ADate`）。
  * **增强代码可读性**：使数据类型的业务含义更加清晰（如用 `Length` 代替 `int`）。
  * **提升代码可移植性**：方便在不同平台上统一定义类型（如自定义 `int64_t`）。
* **判定语法规律**：
  * 在 `typedef` 语句中，位于 `typedef` 和最后一个标识符之间的所有内容为**原本的数据类型**。
  * 位于末尾的最后一个标识符即为**新定义的类型别名**。

> [!note]- 模糊点解析与深度避坑
> 1. **没有创造新类型**：`typedef` 仅提供别名映射，并未在编译器层面创建新的物理内存数据类型。
> 2. **从变量声明到类型别名**：在正常的变量声明（如 `int Length;`）前加上 `typedef`，原来的变量名 `Length` 便转换成了类型别名。
> 3. **与宏定义 `#define` 的本质区别**：`#define` 仅是预编译期的文本替换，而 `typedef` 是由编译器处理的类型检查与别名封装。

## typedef 在结构体与复杂类型中的应用

### 核心速记
* **结构体别名简化**：可以直接将匿名结构体定义为指定别名，大幅简化后续变量声明。
* **复合类型抽象**：不仅支持基本类型和结构体，还支持指针、数组等复合类型的别名定义。

### 典型示例代码
```c
// 1. 基础类型别名
typedef int Length;
Length a, b, len; // 等价于 int a, b, len;

// 2. 结构体类型别名（结合匿名结构体）
typedef struct {
    int month;
    int day;
    int year;
} Date;

Date d = {9, 1, 2005}; // 直接使用 Date 声明变量，无需写 struct

// 3. 数组/指针复合类型别名
typedef char* Strings[10]; // Strings 表示包含 10 个字符指针的数组类型
```

> [!note]- 模糊点解析与深度避坑
> 1. **自引用结构体（如链表节点）的陷阱**：在结构体内部定义指向自身类型的指针时，不能直接使用尚未定义完成的别名：
> 
> ```c
> typedef struct node {
>     int data;
>     struct node *next; // 必须使用 struct node *，不能写为 node * 或 aNode *
> } aNode;
> ```
> 2. **别名唯一定位原则**：当 `typedef` 语句比较繁琐复杂时，牢记寻找最后一个单字标识符作为别名，前面所有组合均为原类型。
