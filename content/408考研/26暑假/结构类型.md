## 1. 结构类型的定义与作用域

### 核心速记
* **定义目的**：当需要用一个整体表达多项不同类型组合的复杂数据（如包含年、月、日的日期或包含时、分、秒的时间）时，基础数据类型和数组无法满足需求，必须使用结构（`struct`） [00:00:21]。
* **语法格式**：使用关键字 `struct` 定义结构类型，大括号内包含成员变量，结尾**必须以分号 `;` 结束** [00:01:17]。
  * `struct 结构名 { 类型1 成员1; 类型2 成员2; ... };` [00:01:17]
* **作用域法则**：
  * **局部声明**：在函数内部声明的结构类型，仅能在该函数内部使用 [00:02:40]。
  * **全局声明**：在所有函数外部声明的结构类型，可被后续所有函数共同共享 [00:03:11]。

> [!warning]- 结构声明结尾分号缺失与作用域坑点
> 1. **初学者最常见编译错误**：漏写结构声明末尾的分号 `;` [00:01:55]。
> 
> ```c
> // 错误写法：漏掉结尾分号，会导致编译器报不明确的语法错误
> struct date {
>     int month;
>     int day;
>     int year;
> } // <-- 缺少分号
> 
> // 正确写法
> struct date {
>     int month;
>     int day;
>     int year;
> }; // <-- 必须保留分号
> ```
> 
> 2. **作用域选型指导**：为提升代码重用度，通常推荐将结构类型的声明放在所有函数外部，避免因声明在 `main` 内部而无法被其他自定义函数引用的尴尬 [00:03:11]。

## 2. 结构声明的三种表现形式

### 核心速记
* **形式一（独立声明，推荐）**：先声明结构类型，后续再单独定义结构变量 `struct point p1, p2;` [00:03:41]。
* **形式二（无名结构）**：不给结构类型起名字，直接在声明大括号后定义变量 `struct { int x; int y; } p1, p2;`，适用于只需一次性使用的场景 [00:04:36]。
* **形式三（声明+定义）**：在声明结构类型的顺便在大括号后定义变量 `struct point { int x; int y; } p1, p2;` [00:05:32]。

> [!note]- 三种声明形式的代码示例与应用场景对比
> 1. **三种写法的代码实现**：
> 
> ```c
> // 形式一：先声明类型，后定义变量（标准、易扩展、最常用）
> struct point {
>     int x;
>     int y;
> };
> struct point p1, p2; // 明确指定变量类型为 struct point
> 
> // 形式二：匿名结构体直接定义变量（无法在后续代码中再用该类型创建新变量）
> struct {
>     int x;
>     int y;
> } p1, p2; // p1 和 p2 是无名结构变量
> 
> // 形式三：同时声明类型并定义变量（兼顾类型定义与变量创建）
> struct point {
>     int x;
>     int y;
> } p1, p2; // 既定义了 struct point，又创建了 p1, p2
> ```

## 3. 结构变量的初始化与成员访问

### 核心速记
* **成员访问规则**：使用点运算符 `.` 访问内部成员（如 `today.day`），**点运算符左边必须是结构变量实体的名称**，绝不能是结构类型名 [00:10:00]。
* **顺序初始化**：按结构内部成员的声明顺序在大括号内依次填充初始值，如 `struct date today = {07, 31, 2014};` [00:07:52]。
* **指定成员初始化**：借助 `.成员名=` 语法初始化特定项，如 `struct date thismonth = {.month=7, .year=2014};`，未显式指定的成员默认填充 0 [00:08:18]。

> [!warning]- 点运算符非法使用与缺失赋值自动补零坑点
> 1. **“结构类型”与“结构变量”的本质区分**：
>    结构类型（如 `struct date`）是虚构的模型，不占用实际内存空间；结构变量（如 `today`）才是占有内存的实体空间 [00:10:51]。
> 
> ```c
> // 致命错误：尝试对“结构类型名”进行点运算访问
> struct date.day = 10; // 编译报错！struct date 是类型，不是变量实体
> 
> // 正确用法：对“结构变量名”进行点运算访问
> struct date today;
> today.day = 10; // 正确
> ```
> 
> 2. **部分赋值的自动补零机制**：
>    当采用指定成员赋值方式（如 `.month=7`）时，未初始化的成员（如 `day`）会自动补零（`0`），其原理与数组的部分初始化逻辑完全一致 [00:09:07]。

## 4. 结构变量的运算与指针取地址

### 核心速记
* **支持整体赋值**：结构变量支持直接相互赋值 `day = today;`，系统会自动将右侧结构体中的所有成员按值拷贝至左侧 [00:11:41]。
* **支持强制类型转换赋值**：可通过 `p1 = (struct point){5, 10};` 进行整体重新赋值，而数组无法进行类似运算 [00:11:50]。
* **独立内存空间**：结构变量互相赋值是纯粹的“值拷贝”，赋值后两个变量改动互不影响 [00:13:58]。
* **强制使用 `&` 取地址**：与数组名本身即代表地址不同，**结构变量名并不代表结构地址**，必须配合取地址运算符 `&` 才能获取指针（如 `&today`） [00:14:18]。

> [!warning]- 结构体整体赋值与数组的对比及指针坑点
> 1. **结构体 vs 数组的运算差异**：
>    * 数组名是常量指针，**不支持**数组间的整体赋值（如不能直接将一个数组赋值给另一个数组）。
>    * 结构变量是实体对象，**支持**结构间的整体赋值（如 `p1 = p2` 合法） [00:12:36]。
> 
> 2. **结构指针类型声明与取地址错误分析**：
> 
> ```c
> struct date today = {07, 31, 2014};
> 
> // 错误写法：把结构变量名当作地址使用
> struct date *pDate = today; // 编译报错！today 不是地址
> 
> // 正确写法：使用 & 符号显式获取结构变量的地址
> struct date *pDate = &today; // 正确，pDate 类型为指向 struct date 的指针
> ```

## 5. 结构体指针与解引用成员访问
### 核心速记
 * **打印限制**：C 语言缺乏支持整个结构体的格式占位符，无法直接打印解引用后的 *p 整体，必须将内部成员拆分后单独格式化打印。
 * **指针访问成员的两种写法**：
   * **箭头运算符 ->（最推荐/最常用）**：直接通过指针访问成员，如 p->year。
   * **解引用加点运算符 (*p).**：先将指针解引用为结构体实体，再通过点运算符访问，如 (*p).year。
 * **解引用 *p 的其他用途**：*p 在逻辑和语义上完全等同于结构体变量实体，支持整体赋值给新结构体（d2 = *p）或作为值传递参数传入函数（func(*p)）。
> [!warning]- 优先级陷阱与 *p 复合应用解析
>  1. ***p.year 编译报错与优先级坑点**：
>    在 C 语言中，点运算符 . 的优先级高于解引用运算符 *。
> ```c
> // 错误写法：等价于 *(p.year)，尝试对指针 p 进行点运算，引发编译器报错
> printf("%d\n", *p.year);
> 
> // 正确写法：加小括号提升优先级，先解引用出结构体实体，再获取成员
> printf("%d\n", (*p).year);
> 
> // 最佳替代方案：使用箭头运算符
> printf("%d\n", p->year);
> 
> ```
>  2. **完整验证代码与 *p 的扩展用法**：
> ```c
> #include <stdio.h>
> 
> struct date {
>     int year;
>     int month;
>     int day;
> };
> 
> void print_date(struct date d) {
>     printf("函数传参打印: %d-%d-%d\n", d.year, d.month, d.day);
> }
> 
> int main() {
>     struct date d1 = {2026, 7, 22};
>     struct date *p = &d1; // p 指向 d1 的内存地址
> 
>     // 1. 方式一：箭头运算符（推荐）
>     printf("箭头访问: %d-%d-%d\n", p->year, p->month, p->day);
> 
>     // 2. 方式二：(*p) 解引用配合点运算符
>     printf("解引用访问: %d-%d-%d\n", (*p).year, (*p).month, (*p).day);
> 
>     // 3. 解引用 *p 的整体拷贝赋值
>     struct date d2 = *p; // 相当于 d2 = d1，将 d1 的数据完整拷贝给 d2
> 
>     // 4. 解引用 *p 作为参数传递给函数
>     print_date(*p);
> 
>     return 0;
> }
> 
> ```
>
