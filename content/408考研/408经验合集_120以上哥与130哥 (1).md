# 三、第一轮学习

## 1. 数据结构

### 时间与日程

- 5月底开始。
- 每天下午2点到6点学习。[P01]

### 学习方法

1. 翻看专业课教材。
2. 每看完一章，做对应课后题。
3. 第一轮只做选择题。
4. 遇到不会的题，查找网络解析辅助理解。[P01]

### 作者对分值和难度的判断

作者认为：

- 真题中数据结构选择题和计算机组成原理占比较大。
- 数据结构选择题整体难度不算大。
- 因此需要重视数据结构选择题。[P01]

这是作者的主观总结，不代表所有年份的命题难度都相同。

---

## 2. 计算机组成原理

### 时间与日程

- 6月中下旬左右开始。
- 每天晚上学习。[P01]

### 学习方法

1. 先跟课程并结合教材学习。
2. 每看完一个小章节，就合上书背写所学知识点。
3. 第一轮不必画完整成型的思维导图。
4. 核心是逼迫自己主动回忆和输出。
5. 大量专业名词需要记忆。[P01]

### 作者强调的原则

- “切忌只看课不看书。”
- “切忌只看书不进脑。”
- 学完一个小章后要做课后题。
- 某个知识点在课程中没有听懂，或者讲解不透彻，就单独拆出来重新学。
- 各类习题解析可以作为对照材料。[P01]

### 与操作系统的交叉

作者认为计算机组成原理较难，且部分章节和操作系统有联系：

- 遇到暂时难以理解的交叉内容，可以先不纠缠。
- 学到操作系统相关内容后，再返回计算机组成原理复习。
- 也可以直接翻开操作系统教材先看对应章节。
- 作者举例：学完计算机组成原理第三章后，就开始学习操作系统中相应的存储相关内容。[P02]

### 对基础差考生的安慰

作者自称“代码白痴”，但认为：

- 计算机组成原理不需要太多代码思维。
- 即使代码基础较差，也不要过早灰心。[P02]

---

## 3. 操作系统

### 时间

- 作者称操作系统比计算机组成原理简单很多。
- 第一轮约10天完成。[P02]

### 学习方法

1. 跟课程并配合教材。
2. 看完教材后，强迫自己画思维导图。
3. 再做选择题。
4. 不理解的选择题，要在学完计算机组成原理后继续回看。[P02]

作者的主观体验是：

> 学完计算机组成原理再学操作系统，会感到更顺畅。[P02]

# 四、第二轮学习

## 1. 时间

- 8月下旬开始。
- 计算机组成原理和操作系统同步进入第二轮。[P02-P03]

## 2. 第二轮核心任务

作者发现：

- 第一轮结束后，仍有很多知识点不会。
- 第二轮需要从头到尾重新翻教材。[P02-P03]

具体流程：

1. 先看对应课程视频。
2. 一个视频看完后，立即返回教材。
3. 用铅笔勾画视频中提到的名词、原理和重要语句。
4. 做课后题。
5. 在A4纸上写知识点和思维导图。
6. 强迫自己主动回忆和输出。[P03]

作者称：

- 第二遍看书时开始逐渐“悟了”。
- 与第一遍的感受完全不同。[P03]

---

## 3. 建立跨章节联系

作者建议：

- 如果前面章节的内容与后面某个部分有关，就在旁边标注后面对应的页码。
- 下次看到这个知识点时，立刻翻到对应页面。
- 用这种方式把不同章节串联起来，建立整体知识结构。[P03]

---

## 4. 开始训练大题

第二轮开始做：

- 计算机组成原理大题。
- 操作系统大题。[P03]

作者的方法：

1. 参考相关讲解获得解题思路。
2. 把课后题解析彻底理解。
3. 大题必须认真亲手写。
4. 在平板上整理错题。
5. 将错题打印出来。
6. 纸质版写正确解法和思路。
7. 电子版用于反复练习。
8. 练到拿出一道题就能迅速形成思路。[P03]

作者同时说明：

- 这一阶段不要求每一步都完全正确。
- 更重要的是建立大题的初步思路。[P03]

# 七、作息与每日时长

## 第二轮阶段的作息

作者称：

- 最晚每天早上7点准时到图书馆。
- 中午可以回宿舍午睡。
- 午睡最多1小时。
- 晚上学习到10点。[P04]

作者经常感觉：

- 数学和408之间的学习时间无法完全平衡。
- 认为这种不平衡属于正常现象。[P04]

## 计算机网络结束后的作息

作者调整为：

- 早上约6点到图书馆。
- 下午整块时间用于408。
- 中午在图书馆趴着午睡约1小时。
- 晚上10点回宿舍。
- 回宿舍后不再学习，主要用于休息。
- 尽量11点闭眼睡觉。
- 即使失眠，也不要闭着眼睛玩手机。
- 第二天早上仍要求自己6点到图书馆。[P04]

## 休息安排

作者称自己：

- 没有固定规律的休息周期。
- 实在坚持不住或身体不适时，会休息一下午加一晚上。[P04]

## 风险提示

该作息是作者个人做法，并不等于普适方案：

- 长期强制早起且缺少固定休息日，可能造成睡眠不足和效率下降。
- “别人休息你不能休息”的表述带有明显的高压和竞争情绪。
- 对普通考生，更应关注有效学习时长、睡眠质量和可持续性，而不是机械复制到馆时间。

# 八、第一遍真题

## 1. 时间

- 10月上旬开始。
- 从2009年真题开始。
- 大约10月底结束第一遍。[P05]

## 2. 做题节奏

- 两天完成一套。
- 第一天做选择题。
- 第二天做大题。
- 做完后立即订正。[P05]

## 3. 复盘方式

- 参考网上不同角度的真题解析。
- 多种讲解互相对照。
- 目标是把考点理解到位。
- 真题必须真正弄懂。
- 错题旁边直接写对应知识点，方便后续快速复习。
- 遇到眼熟知识点，建议回归教材。
- 通过回看教材加深印象。[P05]

## 4. 对真题重复的看法

作者提到：

- 教材课后题中有不少往年考题。
- 前面可能已经做过部分真题题目。
- 但作者认为这不会严重影响整套真题训练。
- 有印象的题不应轻视，没有印象的题也不应灰心。[P05]

## 5. 第一遍分数与心态

作者称：

- 第一遍真题阶段自己的分数没有超过80分。
- 认为低分并不代表最终没有机会，因为距离考试仍有约两个月。
- 即使情绪崩溃，第二天也要继续做真题。
- 分数越低，越要加强后续学习。[P05]

“用疯子的心态去学习”属于作者的情绪化表达，不宜直接照搬。可以保留其“不因一次低分停止训练”的含义，但不应把长期高压、透支或失控视为必要条件。

# 十、作者的整体方法论

## 1. 教材是主线

作者反复强调：

- 课程不能替代教材。
- 第一轮要课程配教材。
- 第二轮要重新从头翻教材。
- 真题阶段仍要回归教材。
- 到后期，作者认为精读教材的效果甚至高于再次听课。[P01-P06]

## 2. 主动输出

贯穿全程的输出方式包括：

- 合上书背写知识点。
- 画思维导图。
- 在A4纸上写框架。
- 在书边标注关联页码。
- 大题亲手完整书写。
- 错题重新打印并重复练习。[P01-P03]

## 3. 先建立思路，再追求完全正确

尤其在计算机组成原理和操作系统大题中：

- 第二轮先练到看到题目就有思路。
- 初期不要求每一步都完全正确。
- 后续通过纸质错题和电子复习逐步提高准确性。[P03]

## 4. 真题至少两遍

- 第一遍两天一套，重理解和订正。
- 第二遍一天一套，重速度、熟练度和教材回归。[P05-P06]

## 5. 不与他人比较进度

作者结尾强调：

- 从5月底开始并不算早。
- 要保持专注投入。
- 不看别人的学习进度。
- 只看自己的学习效果。[P06]

# 十三、值得警惕的地方

## 1. 没有成绩证明

材料只说“想考120分以上可以参考”，没有显示作者实际408分数。

因此：

- 不能确认这是120+考生的完整复盘。
- 更不能把所有做法视为已被最终成绩验证。

## 2. 作息强度很高

作者后期要求自己：

- 早上6点到图书馆。
- 晚上10点回宿舍。
- 没有固定休息日。
- 即使失眠，第二天仍按原计划早起。[P04]

这可能存在：

- 睡眠透支。
- 情绪耗竭。
- 有效时间被表面时长掩盖。
- 身体状态恶化。

## 3. 情绪化表述

例如：

- “用疯子的心态去学习。”
- “别人休息你不能休息。”

这些并非可靠的方法论，只是作者个人表达。真正可保留的是：

- 低分后继续训练。
- 不盲目比较。
- 保持稳定执行。

## 4. 过度依赖自律环境

作者几乎把图书馆、高强度日程和严格自控作为前提。对不能维持这种环境的人，照抄可能很快崩盘。

## 5. 缺少模拟卷与最终冲刺细节

文档主要写到两遍真题和教材回归，没有详细说明：

- 模拟卷数量。
- 正式限时安排。
- 四科做题顺序。
- 考场时间分配。
- 最终分数提升曲线。

# 十四、对机械跨考打底阶段的参考价值

## 当前可直接吸收

### 1. 不只看课，必须回到教材和练习

作者最有价值的原则是：

> 课程理解 → 教材确认 → 课后题检验 → 主动输出。

这对非科班打底尤其重要。

### 2. 学完立刻回忆

可以采用低成本版本：

- 每学完一个小节，合上书写3—5个关键词。
- 口述该节解决了什么问题。
- 写出一个典型题思路。

不必一开始就画完整大思维导图。

### 3. 建立跨章节联系

在教材旁写关联章节和页码，有助于后续理解：

- 计算机组成原理与操作系统。
- 存储系统与内存管理。
- 硬件机制与操作系统抽象。

但具体对应关系仍需以实际教材为准，不能由本文补全。

### 4. 错题需要反复再做

作者不是只收藏错题，而是：

- 整理。
- 打印。
- 手写正确过程。
- 电子版重复练习。

这种“再次独立完成”比单纯摘抄答案有效。

### 5. 真题低分不能立即否定自己

作者第一遍真题未超过80分，仍继续完成第二遍。[P05]

对未来正式备考可借鉴：

- 首轮真题是诊断，不是最终判决。
- 关键是订正后是否真正补掉漏洞。

# 四、作者对四科难度与特点的判断

以下均为作者个人评价，不是统一结论。

## 1. 数据结构

作者认为：

## 2. 计算机组成原理

作者认为：

- 计组涉及底层硬件，整体难度稍高。
- 听课时可能每个知识点都听得懂，题目似乎也会做，但几天后容易忘记。

作者给出的处理方式：

- 可以适当回顾前面章节。
- 也可以先继续推进。
- 如果第一次学习某个难点时，反复听仍然不会，先标记后跳过。
- 要学会“抓大放小”，不要死磕，不要追求完美。[P02]

## 3. 操作系统

作者认为：

- 操作系统主要是概念性内容，需要把概念对应清楚。
- 即使是理工科，408中该背的内容仍需要背。
- 基础课程内容广、散，第一次学习时思路混乱很正常。
- 基础阶段不必强求立刻整理出完整思维导图。
- 先熟悉各个知识点，强化阶段再形成重点和条理。[P03]

## 4. 计算机网络

作者认为：

- 计网是四科中需要记忆内容最多的一门。
- 选择题可能出现冷门知识点。
- 部分内容缺少明显逻辑关联，更接近记忆和背诵。
- 作者本人没有记住所有内容，只记了重要部分。
- 计网理解起来相对简单。

# 十一、作者反复强调的学习原则

## 1. 抓大放小

作者认为：

- 408知识点多而杂，但考试侧重点明显。
- 很难、低频的内容可以在基础阶段先跳过。
- 不应在低回报知识点上死磕。[P02][P09]

作者举例：

- 海明码。
- 除法器。[P09]

作者称：

- 学完强化并做完真题后，会发现部分难点不是考试重点。
- 即使考到，可能多数人都不会。
- 不必在这类内容上过度纠结。[P09]

这属于作者对低频难点的经验判断，不等于这些知识点绝对不会考。

## 2. 不追求完美主义

作者明确建议：

- 第一次学习理解困难时，反复听仍不会就先标记。
- 不要因为一个局部难点停滞整体进度。
- 先完成整体，再通过后续轮次解决。[P02]

## 3. 重复

作者将“重复”视为408的核心：

- 多学几遍。
- 多刺激几遍知识点。
- 通过重复形成“量变产生质变”。
- 作者称自己二战第二遍学习时才真正体会到这一点。[P10]

## 4. 多角度理解

作者建议：

- 同一知识点可以听不同老师。
- 问其他考生。
- 使用AI。
- 接触多种解题思路。
- 目的不是收集资料，而是更完整、灵活地理解知识点。[P04]

# 十五、对机械跨考打底阶段的参考边界

## 当前可以吸收

1. **先建立C语言和数据结构基础**  
   作者是科班且有一战积累；机械跨考生更需要先解决代码、指针和基本数据结构理解。

2. **少资料、多重复**  
   当前无需大量收集408课程。把C语言和数据结构一套主线真正学完，比囤积老师和题库更重要。

3. **第一遍允许不完整**  
   遇到局部难点可以标记，不必因为完美主义停滞整体进度。[P02]

4. **每学一章形成框架**  
   操作系统和计组不要求第一遍就形成完美体系，但要知道每章讲什么、核心概念是什么。[P02-P03]

5. **笔记以可回忆为目标**  
   不做大段抄写。只记录自己易混、易忘、需要重新定位的内容。[P06][P09]

6. **为正式备考预留多轮复习**  
   本帖最稳定的结论是重复，而不是某个老师或某本书。[P10]

## 当前不能直接照搬

1. 现在还不是3—7月正式408基础期，不需要每天投入3—4小时408。
2. 不需要现在开始王道四科全套课程。
3. 不能因为作者说算法和低频难点性价比低，就忽略跨考打底阶段的数据结构代码训练。
4. 不要照搬“基础阶段不做大题”到C语言/数据结构打底；当前必须亲手写代码。
5. 二战7月开始并不意味着一战跨考生也可以拖到7月。
6. 作者的课程和社群推荐带有明显个人偏好与导流，应与其他作者证据交叉验证。

# 十六、最终结论

130哥这份经验的核心不是“7月开始也能130”，而是：

- 一战9月开始，已有118分基础。
- 二战在前一年积累上再次学习，最终130分。
- 作者把提分归因于更早规划、抓大放小、少资料、多轮重复和真题分类训练。[P01][P07-P10]

对首次跨考者最有价值的证据是：

> 第一遍不必追求完美，但必须保持整体推进；真正拉开差距的是后续反复回顾、课后题重做、真题分类和重点知识的多次刺激。[P02][P07-P10]

对当前机械跨考打底阶段，最适合落实的不是立刻照抄三阶段408日程，而是先把C语言和数据结构练到能独立理解代码与基本算法，为以后多轮408复习建立起点。
