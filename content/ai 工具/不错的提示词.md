# 文档一：Termux 快捷键配置指南

这份文档只处理平板本地 Termux 的底部额外按键，不展开服务器工具安装，也不写成大型手册。

## 文档目标

根据我的实际输入方式，重新设计 Termux 的 `extra-keys`：

- 我主要使用带语音输入的安卓虚拟键盘输入中文需求。
    
- 普通虚拟键盘已经具备字母、数字、符号、Shift、退格和回车。
    
- Termux 底部快捷栏只需要补充普通虚拟键盘缺少或不方便使用的终端专用按键。
    
- 删除目前无实际用途的 `F9`、`F10`、`F11`。
    
- 暂时不能确定是否长期使用 tmux 专用宏，因此不要在没有说明的情况下加入过于复杂的 tmux 一键宏。
    
- 优先考虑 `ESC`、`TAB`、`CTRL`、`ALT`、方向键、`Ctrl-C`、粘贴和显示/隐藏键盘等高频功能。
    
- `HOME`、`END`、`PGUP`、`PGDN` 是否保留，应根据实际用途判断，不要为了填满按键而加入。
    
- 快捷栏要适合平板竖屏，避免按钮太多、太窄或标签难以理解。
    

## 文档结构

1. 简单说明为什么要修改快捷栏，以及每类按键解决什么问题。

## 第三部分对tmux的特殊要求

tmux必须写成完整的初学者手册，不能只列几个快捷键。

先详细解释以下层级：

```text
tmux server
└─ session
   └─ window
      └─ pane
         └─ Shell或Codex程序
            └─ Codex对话
```

必须解释：

- tmux session是什么；
    
- tmux window是什么；
    
- tmux pane是什么；
    
- tmux窗口和Android窗口不是一回事；
    
- tmux session和Codex会话不是一回事；
    
- tmux pane和Codex对话不是一回事；
    
- SSH断开、tmux detach、退出Codex、关闭pane、关闭window、删除session分别会发生什么；
    
- 哪些操作只是离开，哪些会终止进程；
    
- 一个项目是否应该对应一个session；
    
- 如何为daily-plan和xitong设计合理结构。
    

tmux快捷键至少覆盖：

- 新建、列出、连接、离开、重命名和删除session；
    
- 新建、切换、选择、重命名和关闭window；
    
- 左右分屏、上下分屏；
    
- 在pane间切换；
    
- 放大和恢复pane；
    
- 调整pane大小；
    
- 关闭pane；
    
- 进入复制和滚动模式；
    
- 查看历史输出；
    
- 查看快捷键帮助；
    
- 重新加载配置；
    
- tmux-resurrect保存与恢复；
    
- tmux-continuum自动保存状态。
    

所有快捷键按日常使用频率排序，并说明：

```text
Ctrl-b，松开，再按字母
```

不是同时长按所有按键。
