**一句话揭露本质：你不是在找日期，你是在找"年份的倒影"！——回文日期的后4位（月日）完全由前4位（年份）强制决定，根本不用一天一天傻找！**

## 🧠 思路诊断

你看你编辑器里已经把日期工具函数（`is_leap`、`get_day`）搭好了，基础零件是齐的，就差"怎么找答案"这一步卡住了。

这道题的核心秘密就一句话：**回文日期的 `yyyyMMdd` 这 8 位数字里，后 4 位的 `MMdd` 就是前 4 位 `yyyy` 的倒序！** 比如年份是 `2021` → 倒过来是 `1202` → 所以回文日期就是 `20211202`。你现在卡壳的原因就是没意识到这个"强制绑定关系"，以为要逐个日期穷举。

## ▶️ 阶段一：暴力骗分（逐日模拟，保底 100% 其实就够了）

先说最笨但最稳的方法：把你笔记里的 **时光机 `get_next()`** 直接掏出来，从 `N+1` 开始一天一天往后走，每走一天就检查这个 8 位数是不是回文、是不是 ABABBABA。

**为什么这个暴力也够用？** 下一个回文日期最多 1~2 年就会出现（因为每年最多一个回文日期），下一个 ABABBABA 最多也就 100 年左右。逐日模拟 365 × 100 ≈ 36500 天，每次只做几次数位比对，C++ 连 1ms 都不用就出结果了。**这题用暴力就是满分！**

```cpp
#include <bits/stdc++.h>
using namespace std;
using ll = long long;

int M_day[13] = {0, 31, 28, 31, 30, 31, 30, 31, 31, 30, 31, 30, 31}; 

bool is_leap(int y) {
    return (y % 4 == 0 && y % 100 != 0) || y % 400 == 0; 
}

int get_day(int y, int M) {
    if (M == 2 && is_leap(y)) return 29; 
    return M_day[M]; 
}

// 【时光机】输入今天8位日期，返回明天8位日期
int get_next(int date) {
    int y = date / 10000;
    int m = (date / 100) % 100;
    int d = date % 100;
    
    d++;
    if (d > get_day(y, m)) {
        d = 1;
        m++;
        if (m > 12) {
            m = 1;
            y++;
        }
    }
    return y * 10000 + m * 100 + d;
}

// 【安检门1】判断8位整数是否是回文
bool is_pal(int x) {
    int a[8];
    int t = x;
    for (int i = 7; i >= 0; --i) {
        a[i] = t % 10;
        t /= 10;
    }
    // 左右对称比对：0-7, 1-6, 2-5, 3-4
    for (int i = 0; i < 4; ++i) {
        if (a[i] != a[7 - i]) return false;
    }
    return true;
}

// 【安检门2】判断是否是 ABABBABA 型
bool is_ab(int x) {
    if (!is_pal(x)) return false;  // 先过回文关
    int a[8];
    int t = x;
    for (int i = 7; i >= 0; --i) {
        a[i] = t % 10;
        t /= 10;
    }
    // ABABBABA: A位 = 0,2,5,7;  B位 = 1,3,4,6
    return (a[0] == a[2] && a[2] == a[5] && a[5] == a[7]) &&
           (a[1] == a[3] && a[3] == a[4] && a[4] == a[6]);
}

int main() {
    ios::sync_with_stdio(0); cin.tie(0); cout.tie(0);
    
    int n;
    cin >> n;
    
    bool f1 = false;  // 回文日期找到没？
    bool f2 = false;  // ABABBABA 找到没？
    
    int curr = get_next(n);  // 从明天开始找！
    
    while (!f1 || !f2) {     // 两个都没找到就不许下班！
        if (!f1 && is_pal(curr)) {
            cout << curr << '\n';
            f1 = true;
        }
        if (!f2 && is_ab(curr)) {
            cout << curr << '\n';
            f2 = true;
        }
        curr = get_next(curr);  // 走向下一天
    }
    
    return 0;
}
```

**这个阶段一代码已经能 AC 了**，因为数据范围小，逐日模拟完全撑得住。

## ▶️ 阶段二：满分正解（年份迭代，O(年数) 极致优雅）

阶段一的代码虽然能过，但作为算法学习者，你得明白它为什么"明明暴力却满分"——**因为回文日期的稀缺性**。下面讲最优思路，本质就是开头那句"年份倒影"。

### 核心心法

回文日期的 8 位数字 `YYYYMMDD`，回文意味着：
- 第 1 位 = 第 8 位
- 第 2 位 = 第 7 位
- 第 3 位 = 第 6 位
- 第 4 位 = 第 5 位

也就是说：**MMDD 就是 YYYY 的倒序！** 年份一旦确定，月和日就被"强制生成"出来了。所以你根本不需要去循环月和日——只需要循环年份，然后：

1. 算出年份的倒序 → 得到 MMDD
2. 拼成完整的 8 位日期
3. 检查这个日期是否合法（月份 1~12，天数不超标）
4. 如果合法且大于输入的 N，就是答案！

### ABABBABA 的年份特征

对着 `ABABBABA` 这个 8 位模板看：
```
A B A B B A B A
↑   ↑     ↑   ↑  ← A 位
  ↑   ↑ ↑   ↑    ← B 位
```

前 4 位（年份）= `A B A B`。所以：**年份本身就是 ABAB 重复结构**！即年份的第 1 位 = 第 3 位，第 2 位 = 第 4 位。

### 代码

```cpp
#include <bits/stdc++.h>
using namespace std;
using ll = long long;

int M_day[13] = {0, 31, 28, 31, 30, 31, 30, 31, 31, 30, 31, 30, 31}; 

bool is_leap(int y) {
    return (y % 4 == 0 && y % 100 != 0) || y % 400 == 0; 
}

int get_day(int y, int M) {
    if (M == 2 && is_leap(y)) return 29; 
    return M_day[M]; 
}

// 【核心引擎】翻转4位年份 → 得到 MMDD
int rev4(int x) {
    int res = 0;
    for (int i = 0; i < 4; ++i) {
        res = res * 10 + x % 10;  // 每次把最后一位"剥"下来，接到 res 尾部
        x /= 10;
    }
    return res;
}

// 【安检门】检查8位日期是否合法
bool is_valid(int date) {
    int y = date / 10000;
    int m = (date / 100) % 100;
    int d = date % 100;
    if (m < 1 || m > 12) return false;
    if (d < 1 || d > get_day(y, m)) return false;
    return true;
}

int main() {
    ios::sync_with_stdio(0); cin.tie(0); cout.tie(0);
    
    int n;
    cin >> n;
    int y0 = n / 10000;  // 提取起始年份
    
    bool f1 = false, f2 = false;
    
    for (int y = y0; y <= 9999; ++y) {
        // 1. 算出年份的"倒影" → 拼成完整回文日期
        int date = y * 10000 + rev4(y);
        
        // 2. 必须严格大于 N
        if (date <= n) continue;
        
        // 3. 安检：月份和天数必须合法
        if (!is_valid(date)) continue;
        
        // 4. 第一个找到的就是下一个回文日期
        if (!f1) {
            cout << date << '\n';
            f1 = true;
        }
        
        // 5. ABABBABA 检测：年份必须是 ABAB 结构
        //    年份4位：a0 a1 a2 a3，要求 a0==a2 && a1==a3
        if (!f2) {
            int a0 = y / 1000;
            int a1 = (y / 100) % 10;
            int a2 = (y / 10) % 10;
            int a3 = y % 10;
            if (a0 == a2 && a1 == a3) {
                cout << date << '\n';
                f2 = true;
            }
        }
        
        if (f1 && f2) break;  // 俩都找到了，收工！
    }
    
    return 0;
}
```

### 为什么阶段二更好？

- 阶段一要逐日模拟，最多 ~36500 天
- 阶段二只需要循环年份，最多 ~80 年（因为题目保证 N ≤ 92200229，年份上限就是 9220 年左右），每次只做一次整数翻转和日期合法性校验，比逐日模拟精简得多
- 而且不需要维护 `get_next()` 的进位逻辑，代码更干净
