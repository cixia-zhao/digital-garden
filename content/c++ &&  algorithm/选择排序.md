### ✍️ 标准语法 (Syntax)
```cpp
void select_sort(int *a, int n) {
    // 外层循环：每次从未排序部分选择一个最小的数
    for (int i = 0; i < n - 1; i++) {
        // 假设当前位置i的元素就是未排序部分的最小值
        int min_index = i; 

        // 内层循环：从未排序部分（i+1 到 n-1）中找到真正的最小值及其索引
        for (int j = i + 1; j < n; j++) {
            // 如果发现一个更小的元素
            if (a[min_index] > a[j]) {
                // 就更新最小值的索引
                min_index = j;
            }
        }

        // 循环结束后，min_index 就是未排序部分最小元素的索引
        // 将它和当前位置i的元素交换
        int temp = a[min_index];
        a[min_index] = a[i];
        a[i] = temp;
    }
}
