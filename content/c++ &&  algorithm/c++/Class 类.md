## 🎯 1. 核心概念：类与对象

在面向对象编程（OOP）中，**类（Class）**和**对象（Object）**是两个最基础的概念。

* **类 (Class)**：是一个抽象的**模板**或**图纸**。它定义了某一类事物应该具备什么状态，能做什么动作。
    * *比喻*：汽车的设计图纸。
* **对象 (Object)**：是根据“类”这张图纸在内存中实际创建出来的**实体**。一个类可以造出无数个不同的对象。
    * *比喻*：根据图纸实际造出来的一辆辆汽车。

> **💡 Qt 视角**
> `QPushButton` 是一个**类**（图纸）。当你写下 `new QPushButton("点击我")` 时，你就在内存里创造了一个真正的按钮**对象**。

## 🏗️ 2. 类的三大组成部分

一个类主要由以下部分构成：

### ① 访问修饰符 (Access Modifiers)
决定了外界能不能直接访问类里面的东西。
* `public`（公开）：谁都可以直接调用和修改（对外提供的接口）。
* `private`（私有）：只有类自己的内部代码可以访问（隐藏内部实现细节）。
* `protected`（受保护）：自己和继承自己的子类可以访问。

### ② 属性 (Member Variables)
对象的状态或数据（通常设为 `private`，通过 `public` 方法来修改）。
* *例子*：按钮的颜色、文字内容、大小。

### ③ 方法 (Member Functions)
对象能执行的动作（通常设为 `public`）。
* *例子*：按钮的 `setText()`、`show()`。

## 🛠️ 3. 构造函数 

**构造函数**是类中一个非常特殊的函数，它在**对象被创建的那一瞬间会自动执行**，主要用来做初始化（比如分配内存、赋初始值）。

**⚠️ 构造函数的三大铁律：**
1.  **名字必须与类名完全相同！**
2.  **绝对没有返回值！**（连 `void` 都不能写）。
3.  **不能手动调用！** 只能在声明变量或使用 `new` 关键字时由系统自动触发。

### 情况 A：默认构造函数（无参构造）
不需要传递任何参数就能完成初始化的构造函数。
如果类里面什么构造函数都没写，C++ 编译器会自动赠送一个隐藏的空默认构造函数。

```cpp
// 在 Qt 中创建标签对象，调用无参构造函数
// 注意：以下两种写法在 C++ 中对于类来说是完全等价的！

QLabel *label1 = new QLabel;   // 写法一：常见简写（推荐）
QLabel *label2 = new QLabel(); // 写法二：带括号明确表示无参
```
### 情况 B：有参构造函数

在创建对象时，必须强制传入一些参数来进行初始化。

```C++
// 调用有参构造函数，在创建标签的同时填入文字
QLabel *label3 = new QLabel("Hello Qt"); 

// 指定父对象（Qt 特有机制，防止内存泄漏）
QLabel *label4 = new QLabel(this); 
```

## ✍️ 4. 代码结构示例

```C++
#include <iostream>
#include <string>

// 定义一个“学生”类
class Student {
private:
    // 属性（私有，外部不能直接改）
    std::string name;
    int age;

public:
    // 1. 默认构造函数（无参）
    Student() {
        name = "未知";
        age = 18;
    }

    // 2. 有参构造函数
    Student(std::string n, int a) {
        name = n;
        age = a;
    }

    // 方法（行为）
    void introduce() {
        std::cout << "我叫 " << name << "，今年 " << age << " 岁。" << std::endl;
    }
};

int main() {
    // 触发默认构造函数 (age 自动变 18)
    Student *s1 = new Student;       
    
    // 触发有参构造函数
    Student *s2 = new Student("张三", 20); 

    s1->introduce(); // 输出: 我叫 未知，今年 18 岁。
    s2->introduce(); // 输出: 我叫 张三，今年 20 岁。

    return 0;
}
```
