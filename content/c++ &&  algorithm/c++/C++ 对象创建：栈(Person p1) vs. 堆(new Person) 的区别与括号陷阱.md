### 🧠 核心概念/问题
搞不清C++中 `Person p1;` 和 `Person* p = new Person();` 这两种创建对象方式的根本区别，特别是为什么一个有括号 `()` 一个没有，导致无法判断何时该用括号。

### 💡 我的思考与解决方案
这两种方式的核心区别在于**内存分配位置**和**变量本身的性质**。

1.  **`Person p1;` -> 在【栈】上创建对象**
    *   **是什么**：`p1` 这个变量本身就是 `Person` 类型的对象实例。
    *   **内存**：分配在**栈 (Stack)** 上。内存由系统自动管理，当 `p1` 离开其作用域（如函数结束）时，它所占用的内存会被自动释放。
    *   **访问**：直接使用点运算符 `.` 来访问成员，如 `p1.name`。

2.  **`Person* p = new Person();` -> 在【堆】上创建对象**
    *   **是什么**：`p` 这个变量是一个**指针 (`Person*`)**，它储存的是一个 `Person` 对象的**内存地址**。对象本身是通过 `new` 操作符在**堆 (Heap)** 上创建的。
    *   **内存**：分配在**堆 (Heap)** 上。堆是一块更大的、自由的内存空间，系统不会自动管理。通过 `new` 分配的内存，**必须**在不需要时手动通过 `delete p;` 来释放，否则会造成内存泄漏。
    *   **访问**：必须使用箭头运算符 `->` 来访问成员，如 `p->name`。`p->name` 本质上是 `(*p).name` 的语法糖，意为“解引用指针p，找到它指向的对象，然后访问其name成员”。

#### 错误尝试 (如果适用)
我一开始认为 `Person p1()` 应该是在栈上创建对象的正确写法，因为它看起来和 `new Person()` 更对称。但这在C++中是错误的。编译器会把 `Person p1();` 解析成一个名为 `p1`、返回 `Person` 对象的**函数声明**，而不是对象定义。这就是所谓的“最令人烦恼的解析”(Most Vexing Parse)。

#### 正确路径 / 关键代码
**括号 `()` 的使用规则本质上是区分“变量声明”和“函数调用”。**

| 场景 | 目的 | 正确写法 | 解释 |
| :--- | :--- | :--- | :--- |
| **栈** | 调用**默认**构造函数 | `Person p1;` | **不能加括号**，否则会被当成函数声明。 |
| **栈** | 调用**带参数**构造函数 | `Person p1("Tom");` | 必须用`()`来传递参数。 |
| **堆** | 调用**默认**构造函数 | `new Person();` | `new`后面是明确的创建指令，`()`代表调用构造函数，是标准写法。 |
| **堆** | 调用**带参数**构造函数 | `new Person("Tom");` | 必须用`()`来传递参数。 |

```cpp
#include <iostream>
#include <string>

class Person {
public:
    std::string name;
    Person() { // 默认构造函数
        std::cout << "A person is born on the stack/heap." << std::endl;
    }
    ~Person() { // 析构函数，用于观察对象何时被销毁
        std::cout << name << " is destroyed." << std::endl;
    }
};

void demo() {
    // 栈对象：p1就是对象本身。函数结束时，p1自动销毁。
    Person p1; 
    p1.name = "StackPerson";

    // 堆对象：p_ptr是指针，储存了堆上对象的地址。
    Person* p_ptr = new Person();
    p_ptr->name = "HeapPerson";

    // 堆对象必须手动释放，否则demo()结束后它依然存在，造成内存泄漏。
    delete p_ptr; 
    p_ptr = nullptr; // 好习惯：delete后将指针置空

} // p1在这里自动销毁

int main() {
    demo();
    return 0;
}
```

**栈上声明对象调默认构造时，一定别加括号！其他情况（堆上`new`、或调用带参构造）都老老实实加上括号 ：就是调用无参构造函数。**
