**一句话揭露本质：`cnt[x]++` 就是算法界用【空间换时间】的最强阳谋！它逼着你把脑子里“去人群里挨个找人”的穷举思维，强制升级成了“让数据自己按号入座”的上帝视角！**

数据本身当成数组下标”**这种极其反直觉的操作。平时我们用数组，下标 `0, 1, 2` 只是座位的编号，里面装的才是数据；但在频率统计里，**数据就是座位号，里面装的是人数！**



---

### 🧠 顶级心法：什么是“信箱记账法”？

想象一下，操场上有 10 万个学生，学号从 1 到 10 万。现在你想知道：**学号为 888 的学生有几个？**

- **小白的本能（$O(N^2)$ 嵌套循环）：**
    
    跑到操场上，抓住第一个学生问：“你是 888 吗？”跑到第二个问：“你是 888 吗？”……问完 10 万人，累吐血了。这就是你写两个 `for` 循环挨个比对的代价。
    
- **高手的本能（$O(N)$ 频率统计）：**
    
    在操场门口提前放 10 万个透明信箱，编号 1 到 100000。
    
    学生只要一进操场，你看一眼他的学号（比如 `x`），就往第 `x` 号信箱里扔一枚硬币（**这就是 `cnt[x]++`！**）。
    
    等所有人进场完毕，你想知道 888 号有几个人，直接走到 888 号信箱面前，数里面的硬币就行了（**这就是直接读取 `cnt[888]`！**）。

### 💻 肌肉记忆：闭眼都能敲出来的“三步走”模板

以后遇到频率统计，不要犹豫，直接默写这三步：

C++

```
#include <iostream>
using namespace std;

// 【第一步：打造信箱】
// 🚨 极其重要：必须定义在全局！这样不仅能开到 10^7 这么大，而且默认里面全是 0（空信箱）！
const int N = 100005; // 题目说数字最大是多少，你就开多大，再稍微多给 5 个防溢出
int cnt[N]; 

int main() {
    int n;
    cin >> n;
    
    // 【第二步：学生入场，疯狂投币】
    for (int i = 0; i < n; ++i) {
        int x;
        cin >> x;
        cnt[x]++; // 灵魂一步：读到数字 x，就往 x 号信箱扔一枚硬币！
    }
    
    // 【第三步：上帝视角，盘点信箱】
    for (int i = 1; i < N; ++i) { // 遍历所有的数字
        if (cnt[i] > 0) {
            // 这里可以做任何事！
            // 比如找单身狗：if (cnt[i] == 1)
            // 比如找海王：if (cnt[i] > 1)
            // 比如找根本没出现的数字：if (cnt[i] == 0)
        }
    }
    return 0;
}
```

### 🐕 猎犬嗅觉：什么时候该拔出这把武器？

以后做题，只要题目里**同时满足以下两个条件**，这把武器就会嗡嗡作响，甚至连排序（`sort`）都不需要用了：

1. **数据范围极其配合**：题目告诉你，每个数字 $a_i$ 的大小在 $1$ 到 $10^6$ 甚至 $10^7$ 之间。（如果 $a_i$ 是 $10^9$，就不能开这么大的数组了，那时候才需要用 `std::map`，这是后话）。
    
2. **出现这四个关键词**：
    
    - **“次数/频率”**：谁出现了最多次？谁没出现？
        
    - **“去重”**：输出所有不同的数字（只要 `cnt[i] > 0` 就输出）。
        
    - **“配对/抵消”**：比如咱们刚刚做的班级活动，几个凑一对？
        
    - **“排序”**：没错，当你顺着信箱编号 `1` 到 `N` 遍历一遍，把里面有硬币的数字拿出来，**它天然就是排好序的！**（这叫计数排序，速度吊打 `sort`）。
        

### 💡 导师敲黑板

你用不熟的原因，往往是在第二步（投币）和第三步（盘点）之间大脑短路了。

**死死记住：**

- `x` 是原始数据。
    
- `cnt[x]` 是这个数据出现的次数。
    
    一旦把这两个东西在脑子里分开，你的代码逻辑就会像玻璃一样透明！
    


# P11001 [蓝桥杯 2024 省 Python B] 连连看

## 题目描述

小蓝正在和朋友们玩一种新的连连看游戏。在一个 $n \times m$ 的矩形网格中，每个格子中都有一个整数，第 $i$ 行第 $j$ 列上的整数为 $A_{i,j}$。玩家需要在这个网格中寻找一对格子 $(a,b)$ 和 $(c,d)$ 使得这两个格子中的整数 $A_{a,b}$ 和 $A_{c,d}$ 相等，且它们的位置满足 $|a-c| = |b-d| > 0$。请问在这个 $n \times m$ 的矩形网格中有多少对这样的格子满足条件。

## 输入格式

输入的第一行包含两个正整数 $n$ 和 $m$，用一个空格分隔。

接下来是 $n$ 行，第 $i$ 行包含 $m$ 个正整数 $A_{i,1}, A_{i,2}, \dots, A_{i,m}$，相邻整数之间用一个空格分隔。

## 输出格式

输出一行包含一个整数表示答案。

## 输入输出样例 #1

### 输入 #1

```
3 2 
1 2 
2 3 
3 2

```

### 输出 #1

```
6
```

## 说明/提示

一共有以下 6 对格子：$(1,2)−(2,1)$，$(2,2)−(3,1)$，$(2,1)−(3,2)$，$(2,1)−(1,2)$，$(3,1)−(2,2)$，$(3,2)−(2,1)$。

### 数据范围

对于 $20\%$ 的评测用例，$1 \leq n, m \leq 50$；

对于所有评测用例，$1 \leq n, m \leq 1000$，$1 \leq A_{i,j} \leq 1000$。

```cpp
#include <bits/stdc++.h> 
using namespace std;
using ll = long long; // 养成好习惯，虽然你下面把 ans 改成了 int 也过了，但大数据的题最好用 ll 兜底

int n, m; // n 是场地的行数，m 是场地的列数
const int N = 1e3+9; // 题目说数字最大是 1000。我们开到 1009，多给几个空房间当“缓冲带”，防止越界

// 【第一步：打造两栋超级大楼（二维信箱）】
// mcnt 代表 Main diagonal (主对角线 \ 方向)
// acnt 代表 Anti diagonal (副对角线 / 方向)
// 数组维度设计：[数字的值][对角线的编号]
int mcnt[N][N+N]; // N+N 是因为对角线编号最大能达到 n+m，所以开到 2000 多绝对够用
int acnt[N][N+N];

int main()
{
    // 【起飞咒语】切断 C++ 和 C 的输入输出绑定，让 cin/cout 速度飙升
    ios::sync_with_stdio(0); cin.tie(0); cout.tie(0); 
    
    cin >> n >> m; // 读取场地大小：n 行 m 列
    
    // 【第二步：全场大扫描，按规矩投币】
    for(int i = 1; i <= n; ++i) // 枚举每一行
    {
        for(int j = 1; j <= m; ++j) // 枚举每一列
        {
            int x;
            cin >> x; // 读到当前站在 (i, j) 位置的数字 x
            
            // 🎯 核心逻辑 1：计算左斜线 (\) 的身份证号
            // 本来应该是 i - j，但为了防止出现负数下标导致 RE 报错，我们强行加上 m 把它抬高！
            // 拿着数字 x，去 mcnt 大楼的第 x 层，找到编号为 i-j+m 的房间，扔一枚硬币！
            mcnt[x][i - j + m]++;
            
            // 🎯 核心逻辑 2：计算右斜线 (/) 的身份证号
            // 这条线上所有的格子，行号+列号永远是一个固定常数。
            // 拿着数字 x，去 acnt 大楼的第 x 层，找到编号为 i+j 的房间，扔一枚硬币！
            acnt[x][i+j]++;
        }
    }
    
    // 【第三步：上帝视角，盘点大楼里所有的房间】
    int ans = 0; // 准备一个小本本记录总对数
    
    // 遍历大楼的每一层（就是遍历所有出现过的数字，题目说数字最大 1000）
    // 这里你写了 N-2 (也就是 1007)，刚好完美避开了越界，又覆盖了 1~1000 的所有数字，聪明！
    for(int i = 1; i <= N-2; ++i) 
    {
        // 遍历这层楼里的每一个对角线房间
        // 房间号最大不会超过行数列数之和，所以 j 查到 n+m 就足够了，绝不漏网
        for(int j = 1; j <= n+m; ++j) 
        {
            // 🔍 查房 1：查左斜线大楼
            int k1 = mcnt[i][j]; // 看看第 i 层，第 j 号左斜线房间里，有几枚硬币（几个同类）？
            if(k1 > 1) // 如果只有 1 个单身狗，连不了线；必须大于 1 才能玩连连看
            {
                // 算力结算：k1 个人互相连线，每人能连 k1-1 个目标
                ans +=  k1 * (k1-1) ; 
            }
            
            // 🔍 查房 2：查右斜线大楼
            int k2 = acnt[i][j]; // 看看第 i 层，第 j 号右斜线房间里有几枚硬币
            if(k2 > 1) // 同理，有同伴才连线
            {
                ans +=  k2 * (k2-1) ; 
            }
        }
    }
    
    // 【交卷！】
    cout << ans <<'\n';
    
    return 0;
}
```
