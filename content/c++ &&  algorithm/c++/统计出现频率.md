**一句话揭露本质：`cnt[x]++` 就是算法界用【空间换时间】的最强阳谋！它逼着你把脑子里“去人群里挨个找人”的穷举思维，强制升级成了“让数据自己按号入座”的上帝视角！**

数据本身当成数组下标”**这种极其反直觉的操作。平时我们用数组，下标 `0, 1, 2` 只是座位的编号，里面装的才是数据；但在频率统计里，**数据就是座位号，里面装的是人数！**

### 🧠 顶级心法：什么是“信箱记账法”？

想象一下，操场上有 10 万个学生，学号从 1 到 10 万。现在你想知道：**学号为 888 的学生有几个？**

- **小白的本能（$O(N^2)$ 嵌套循环）：**
    
    跑到操场上，抓住第一个学生问：“你是 888 吗？”跑到第二个问：“你是 888 吗？”……问完 10 万人，累吐血了。这就是你写两个 `for` 循环挨个比对的代价。
    
- **高手的本能（$O(N)$ 频率统计）：**
    
    在操场门口提前放 10 万个透明信箱，编号 1 到 100000。
    
    学生只要一进操场，你看一眼他的学号（比如 `x`），就往第 `x` 号信箱里扔一枚硬币（**这就是 `cnt[x]++`！**）。
    
    等所有人进场完毕，你想知道 888 号有几个人，直接走到 888 号信箱面前，数里面的硬币就行了（**这就是直接读取 `cnt[888]`！**）。

### 💻 肌肉记忆：闭眼都能敲出来的“三步走”模板

以后遇到频率统计，不要犹豫，直接默写这三步：

C++

```
#include <iostream>
using namespace std;

// 【第一步：打造信箱】
// 🚨 极其重要：必须定义在全局！这样不仅能开到 10^7 这么大，而且默认里面全是 0（空信箱）！
const int N = 100005; // 题目说数字最大是多少，你就开多大，再稍微多给 5 个防溢出
int cnt[N]; 

int main() {
    int n;
    cin >> n;
    
    // 【第二步：学生入场，疯狂投币】
    for (int i = 0; i < n; ++i) {
        int x;
        cin >> x;
        cnt[x]++; // 灵魂一步：读到数字 x，就往 x 号信箱扔一枚硬币！
    }
    
    // 【第三步：上帝视角，盘点信箱】
    for (int i = 1; i < N; ++i) { // 遍历所有的信箱
        if (cnt[i] > 0) {
            // 这里可以做任何事！
            // 比如找单身狗：if (cnt[i] == 1)
            // 比如找海王：if (cnt[i] > 1)
            // 比如找根本没出现的数字：if (cnt[i] == 0)
        }
    }
    return 0;
}
```

### 🐕 猎犬嗅觉：什么时候该拔出这把武器？

以后做题，只要题目里**同时满足以下两个条件**，这把武器就会嗡嗡作响，甚至连排序（`sort`）都不需要用了：

1. **数据范围极其配合**：题目告诉你，每个数字 $a_i$ 的大小在 $1$ 到 $10^6$ 甚至 $10^7$ 之间。（如果 $a_i$ 是 $10^9$，就不能开这么大的数组了，那时候才需要用 `std::map`，这是后话）。
    
2. **出现这四个关键词**：
    
    - **“次数/频率”**：谁出现了最多次？谁没出现？
        
    - **“去重”**：输出所有不同的数字（只要 `cnt[i] > 0` 就输出）。
        
    - **“配对/抵消”**：比如咱们刚刚做的班级活动，几个凑一对？
        
    - **“排序”**：没错，当你顺着信箱编号 `1` 到 `N` 遍历一遍，把里面有硬币的数字拿出来，**它天然就是排好序的！**（这叫计数排序，速度吊打 `sort`）。
        

### 💡 导师敲黑板

你用不熟的原因，往往是在第二步（投币）和第三步（盘点）之间大脑短路了。

**死死记住：**

- `x` 是原始数据。
    
- `cnt[x]` 是这个数据出现的次数。
    
    一旦把这两个东西在脑子里分开，你的代码逻辑就会像玻璃一样透明！
