判断两字符串接龙重合长度（读第一个就返回版）：
```cpp
// 鉴定专家：看看单词 a 的尾巴，和单词 b 的头，能不能接上？
// 如果能，返回【最短】的重合长度；如果不能，返回 0。
int get_overlap(string a, string b) {
    int min_len = min(a.length(), b.length());
    // 重合部分必须小于两个单词的自身长度（题目规定不能存在包含关系）
    for (int k = 1; k < min_len; k++) { 
        // a.substr(起始位置) 截取 a 的尾巴
        // b.substr(0, k) 截取 b 的头
        if (a.substr(a.length() - k) == b.substr(0, k)) {
            return k; // 从小到大找，找到的第一个就是最短的！直接返回！
        }
    }
    return 0; // 找不到重合部分，接不上
}

```

## `string` 数组
C++ `string` 数组的核心精髓可以浓缩为以下三条“铁律”：

### 1. 本质：两层嵌套的“收纳盒”

`string` 数组不仅是一个存放了多段文本的列表，因为文本（字符串）本身也是由一个个字母/数字组成的，所以它自带“两维”属性：

- **外层**：装着多个字符串的大数组。
    
- **内层**：装着具体字符的小数组（即字符串本身）。
    

### 2. 定位秘籍：方括号 `[ ]` 的用法

记住**“先选大件，再找小件”**，并且**永远从 0 开始数**：

|**代码写法**|**作用**|**提取出的类型**|**举例参考**|
|---|---|---|---|
|**单方括号 `[i]`**|抽取出第 `i+1` 个**完整的字符串**|字符串 (`string`)|`[0]` 拿到 `"1111110"`|
|**双方括号 `[i][j]`**|抽取出该字符串里的第 `j+1` 个**具体字符**|单个字符 (`char`)|`[0][6]` 拿到 `'0'`|

### 3. 安全红线：绝不越界

- **总数减一**：如果大数组里有 10 个字符串，你最多只能查到 `[9]`。
    
- **长度减一**：如果某个字符串长度是 7，你最多只能查到 `[6]`。
    
- 试图跨越边界（比如去查 `[0][7]`）就是去了不属于你的内存地盘，程序极大概率会直接崩溃。
