### 🎯 核心知识
> 定义：用来存储多个数据的最简单的数据结构。
	数组名即首地址 = 首元素的地址 （值一样）。 即& arr = & arr[0]
		内存地址即根据下标偏移，int则每个内存地址偏移4位  
	这就是为什么 数组下标第一位是0，实际下标为偏移量，接近底层硬件原理。

>越界：
>1.声明的大小小于实际存进去的大小；
>2.下标越界
>

```cpp
// 准备工作
bool a[1005]; // a就是我们的开关面板，a[j]代表第j盏灯的状态
              // bool类型只有true(1)和false(0)，正好代表开和关
memset(a, 0, sizeof(a)); // 把所有灯都初始化为0 (false)，也就是“关”

// ... cin >> n >> k; ...

// 核心模拟过程
for (int i = 1; i <= k; i++)      // (1) 外层循环：代表第 i 个人
    for (int j = 1; j <= n; j++)  // (2) 内层循环：这个人去检查从第1到第n的每一盏灯
        if (j % i == 0)           // (3) 判断：如果灯j的编号是i的倍数
            a[j] = !a[j];         // (4) 操作：就按下开关 (状态翻转)
```
