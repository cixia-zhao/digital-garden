# 💡 我的思考与解决方案 (My Thoughts & Solution)

> 外层控制行，内层控制列，外层永远比内慢，因为内层很多行，要等他们全部执行完外层才动一个。
> **记住：这是写给未来的你，不是写给别人。怎么直白怎么来。**

### 错误尝试 (如果适用)

> 打印的时候第一个打印内层的，因为i并不是从一开始，它代表的是行号.,所以应该打印j。

```cpp

      using namespace std;
   
      int main(){
   
      for(int i = 1;i <= 9;i++){
```
