### 1. 基础运算（直接用，告别 C 语言的遗留包袱）

- `abs(x)`：**绝对值**（整数和小数都能直接用，别再写 `fabs` 了）。
    
- `pow(base, exp)`：**次方** $base^{exp}$。
    
- `sqrt(x)`：**平方根**。
    
- `cbrt(x)`：**[C++11] 立方根**。
    
- `hypot(x, y)`：**[C++11] 算斜边**（直接出 $\sqrt{x^2 + y^2}$ 的结果，防溢出神器）。
    

### 2. 取整与取余（别再自己强转 `int` 踩精度坑了）

- `ceil(x)`：**向上取整**。
    
- `floor(x)`：**向下取整**。
    
- `trunc(x)`：**[C++11] 截断取整**（无情切掉小数部分）。
    
- `round(x)`：**[C++11] 四舍五入**。
    
- `fmod(x, y)`：**小数取余**（符号和 x 相同）。
    
- `remainder(x, y)`：**[C++11] 找最近的偶数舍入取余**。
    

### 3. 指数与对数

- `exp(x)`：**自然指数** $e^x$。
    
- `exp2(x)`：**[C++11] 以2为底** $2^x$。
    
- `log(x)`：**自然对数** $\ln(x)$。
    
- `log10(x)`：**常用对数** $\log_{10}(x)$。
    
- `log2(x)`：**[C++11] 以2为底对数** $\log_2(x)$。
    

### 4. 最值与边界控制

- `fmax(x, y)`：**找最大**（比普通的 `max` 更擅长处理浮点数边界）。
    
- `fmin(x, y)`：**找最小**。
    
- `fdim(x, y)`：**算正差值**（如果 $x > y$ 就是 $x - y$，否则强制保底归 0）。
    

### 5. 几何三角计算（注意：全都是弧度制）

- **基础**：`sin(x)`、`cos(x)`、`tan(x)`。
    
- **反向找角度**：`asin(x)`、`acos(x)`、`atan(x)`。
    
- **计算象限角**：`atan2(y, x)`（神级函数，算 $(x,y)$ 向量的极角，自动处理 4 个象限，正负号绝不搞错）。
    

### 6. 异常数据排雷兵 [C++11 新增]

当你做除法或者复杂运算，怕程序因为除以 0 崩溃卡死的时候，提前用这三个探探路：

- `isnan(x)`：判断是不是**非数字**（比如 0.0 / 0.0）。
    
- `isinf(x)`：判断是不是**无穷大**（比如 1.0 / 0.0）。
    
- `isfinite(x)`：判断是不是**正常合法的有限数字**。
