## 🎯 核心功能 (Purpose)

**定义**：迭代器的作用类似于内存地址（或指针变量），主要用于**定位、访问和遍历** C++ STL 容器内部的元素。

## ✍️ 标准语法 (Syntax)

> **注意**：必须在定义并初始化好具体的容器（如 `vector`）之后，才能定义其对应的迭代器。

不同的容器和泛型类型，对应着不同的迭代器类型。以下以 `vector<int>` 为例：



```C++
// 1. 定义迭代器变量 p，并将其初始化为指向容器 v 的首元素
vector<int>::iterator p = v.begin(); 

// 2. 迭代器支持类似指针的算术运算，通过解引用 (*) 获取对应位置的元素
cout << *(p + 1) << endl; 

// 3. 常见的迭代器遍历写法
// v.end() 指向的是容器最后一个元素的下一个位置（超尾）
for (; p != v.end(); ++p) {
    cout << *p << endl;
}
```

**补充说明：**

- `容器.begin()`：获取指向容器第一个元素的头迭代器。
    
- 迭代器支持通过加减法进行偏移（例如 `v.begin() + 1` 指向第二个元素），其底层逻辑类似于指针变量数组的平移。
    

## 🛠️ 常用操作与相关方法

### 1. 容器的快速访问与清理

以下是几个无需显式调用迭代器即可操作容器的常用内置方法：

- `.front()`：获取容器中的**第一个元素**。
    
- `.back()`：获取容器中的**最后一个元素**。
    
- `.clear()`：**清除**容器中的所有元素。
    

### 2. 结合迭代器的插入与删除

在特定位置插入或删除元素时，需要传入迭代器来定位：



```C++
// 插入 (Insert)
// 在指定的迭代器位置直接插入元素。
// 这里表示在第二个位置 (v.begin() + 1) 插入数字 5
v.insert(v.begin() + 1, 5); 

// 删除 (Erase)
// 删除指定迭代器位置上的元素。
// 这里表示删除第二个位置 (v.begin() + 1) 的元素
v.erase(v.begin() + 1);
```
