# C++ 输入输出格式控制
### 保留n位小数
```cpp
cout << fixed << setprecision(n) << b <<'\n';
```
### 补前置0 和设置位宽n
```cpp
cout << setfill('0') << setw(n) << b <<'\n';
```
### 读入技巧
```cpp
char c1, c2, c3, c4; // C++ 输入魔法：海关吞噬法，专门用来吃掉 - 和 :
int Y, M, D, h, m, s;
// 假设读入格式为 2024-02-28 14:30:00 (自动跳过中间的空格)
cin >> Y >> c1 >> M >> c2 >> D >> h >> c3 >> m >> c4 >> s
```
