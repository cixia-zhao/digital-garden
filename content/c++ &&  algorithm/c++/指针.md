### 🎯 核心功能 (Purpose)
> 前置知识 -内存单元和内存地址。
> 内存单元：用来存储二进制数据，根据不同的机型，有不同的存储大小，通常都是8位。
> 内存地址：就是内存单元的地址，可以通过知道内存单元的地址得到内存单元里面的数据。
>指针定义：一种特殊的复合的类型（一种基础的类型，加上*），指针变量是用来存储内存地址的。

### ✍️ 标准语法 (Syntax)
```cpp
int value = 10;
int &ref = value;  // 引用
int *ptr = &value; // 指针

// 使用引用（更简洁）
ref = 20;          // 看起来就像操作原变量

// 使用指针（需要解引用）
*ptr = 20;         // 需要*操作符
```
例子
```cpp
#include <iostream>
using namespace std;

int main() {
    int original = 100;
    
    // 引用版本
    int &ref = original;
    ref = 200;  // 实际上修改的是original
    cout << original << endl;  // 输出200
    
    // 指针版本（等价的底层操作）
    int *ptr = &original;
    *ptr = 300;  // 需要显式解引用
    cout << original << endl;  // 输出300
    
    return 0;
}
```
