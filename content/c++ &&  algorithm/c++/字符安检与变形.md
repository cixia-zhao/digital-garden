# 字符安检与变形

这类函数直接传入单个字符 `c`，非常适合字符串模拟题。

## 判断类函数

- `isdigit(c)` ：判断是否为数字（'0' 至 '9'）
- `isalpha(c)` ：判断是否为字母（'a' 至 'z'、'A' 至 'Z'）
- `isalnum(c)` ：判断是否为字母或数字
- `ispunct(c)` ：判断是否为标点符号（除字母、数字、空格外的可见字符）
- `isspace(c)` ：判断是否为空白符（空格、换行 `\n`、制表符 `\t`）
- `islower(c)` ：判断是否为小写字母
- `isupper(c)` ：判断是否为大写字母

## 转换类函数

- `tolower(c)` ：将字符转换为小写（非字母原样返回）
- `toupper(c)` ：将字符转换为大写（非字母原样返回）
