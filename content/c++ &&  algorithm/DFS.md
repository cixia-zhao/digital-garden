### 🎯 概念
 一句话揭露本质：DFS 不是一门需要你脑力全开去“想象”的魔法，而是一套只需要你像无情机器一样回答“灵魂三问”的工业流水线。
虽然你没有直接发送“原子笔记”四个字，但你的“开始总结”指令已经触发了我们复盘的最佳时机。这份为你量身定制的 DFS 核心模型对比与避坑指南，将把你这两天的顿悟彻底锁死在肌肉记忆里。
📊 四大经典 DFS 模型全景对比

| 题目模型 | `dfs(x)` 中 `x` 的视角 | 眼前有几条路？（动作展开） | 状态数组与恢复现场 | 出口条件 |
| :--- | :--- | :--- | :--- | :--- |
| **1. 跳台阶** (纯粹单向试探) | 我正站在第 `x` 级台阶 | 只有 **2个物理动作**：`dfs(x+1)` 和 `dfs(x+2)` | **不需要！**没有使用全局记事本，参数局部传递，绝不回头。 | `x == n` (成功) 或 `x > n` (撞墙) |
| **2. 子集** (选或不选) | 我正面对着数字 `x` | 只有 **2种主观决策**：选它 (`st[x]=1`)，或不选它 (`st[x]=2`) | **必须恢复！**(`st[x]=0`)。虽然这题特殊可以直接覆盖，但养成习惯，用完全局数组要擦黑板。 | `x > n` |
| **3. 全排列** (填坑模式) | 我正在填第 `x` 个坑 | **n种可能 (引入for循环)**：只要库存里有的数字，全部拿出来试一遍。 | **arr不用恢复**(会被覆盖)。**st必须恢复**(查库存用的，试完必须放回篮子 `st[i]=false`) | `x > n` |
| **4. 组合** (不回头模式) | 我正在填第 `x` 个坑 | **有限种可能 (引入start)**：`for(i=start; i<=n)` 只能拿比前面更大的数字。 | **都不需要！**彻底干掉`st`数组。按顺序拿绝对不会重复，`arr`等待被覆盖即可。 | `x > r` |



💡 你的专属“踩坑与顿悟”记录
回顾这两天的推演，你踩过的坑极其经典，你的顿悟也极其深刻：
❌ 误区 1：被“上帝视角”反噬（企图脑补整棵树）
 * 你的痛苦：看图能懂，一写代码就废，总想在脑子里把递归的所有支路走完（滑动窗口后遗症）。
 * 你的顿悟：人类的大脑内存跑不了递归树！写 DFS 必须化身**“极度短视的机器人”，只需死死盯住“灵魂三问”**：
   * 我是谁？到终点没？（出口 if）
   * 我眼前能迈哪几条腿？（for 循环或直接调用 dfs）
   * 我退回来时需要擦除全局痕迹吗？（恢复现场）
❌ 误区 2：死记硬背“恢复现场”
 * 你的痛苦：知道要还原，但不知道还原谁，在哪还原。
 * 你的顿悟（极其精彩的发现！）：
   * 被直接覆盖的变量（比如全排列里的 arr[x] = i，或者子集里立刻被重写的 st[x] = 2），不需要还原。
   * 作为条件判断的全局变量（比如全排列里的库存清单 st[i]），由于别的平行宇宙还要查阅它，用完必须还原（st[i] = false）！
❌ 误区 3：全排列 return 后的时空错乱
 * 你的痛苦：在 n=2 时，打印完 1 2 退回 dfs(2)，以为还会继续乱跑。
 * 你的顿悟：明白了函数调用栈的“后进先出”。退回来后，会接着执行恢复现场的代码，然后 for 循环 i++。因为 i 越界（i=3 > n），循环彻底结束，从而丝滑地退回到 dfs(1)。
❌ 误区 4：没有利用数学关系进行“剪枝”
 * 你的痛苦：组合题走到死胡同才发现没萝卜了。
 * 你的顿悟：在 for 循环中加入可行性剪枝条件 i <= n - r + x。通过对比“手里的萝卜”和“剩下的坑”，提前砍掉注定失败的分支，这就是算法竞赛拿满分的关键。
🎯 给未来自己的话
> 当你以后面对任何复杂的 DFS 题目（走迷宫、八皇后、图的遍历）脑子发晕时，请立刻停止想象，在纸上画一个“坑”，问自己：这个坑的出口在哪？这个坑能填几个萝卜？填完拔出来时需要把萝卜洗干净放回原处吗？





### ✍️ 例题代码
题目：选数

>![[Pasted image 20260313191146.png]]

```cpp
#include <bits/stdc++.h>
using namespace std;
const int N = 160;
int a[N],q[N];
int n,k,res;
bool is_prime(int x)
{
	if(x < 2) return false;
	for(int i = 2;i <= x / i;++i)
	{
		if(x % i == 0) return false;
	}
	
	return true;
}
void dfs(int x,int sta)
{
	if(x > k)
	{
	  int sum = 0;
		for(int i = 1;i<=k;++i)
		{
			sum += a[i];
		}
		
		if(is_prime(sum)) res++;
		
		return ;
	}
	
	
	for(int i = sta;i <= n+x-k;++i)
	{
		a[x] = q[i];
		dfs(x+1,i+1);
	}
	
}

int main()
{
	cin >> n >> k;
	for(int i = 1;i<=n; ++i) cin >> q[i];
	dfs(1,1);
	cout << res <<'\n';
	return 0;
 } 
```
