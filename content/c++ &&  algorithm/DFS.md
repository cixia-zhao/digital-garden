## 看见求和 方案总数 无脑 全部longl long(包括数组)

在 DFS 里，没有循环，DFS 的每一次运行，就是一段独立的人生。
要达到“回到最头部重新开始”的效果，唯一的办法就是**再次呼叫这个函数自身（传参进入下一层）** 随后return ；销毁当前错误的自己；

DFS 结构中，只要某个状态是**“不合法”**、**“需要跳过”**、或者**“已经达成目标”**的，处理完（或者传给下一层后），立刻、马上接一个 `return;`！** 坚决不能让残废的状态继续往下走去弄脏后面的核心分支！


### 🎯 概念
 一句话揭露本质：DFS 不是一门需要你脑力全开去“想象”的魔法，而是一套只需要你像无情机器一样回答“灵魂三问”的工业流水线。

📊 四大经典 DFS 模型全景对比

| 题目模型 | `dfs(x)` 中 `x` 的视角 | 眼前有几条路？（动作展开） | 状态数组与恢复现场 | 出口条件 |
| :--- | :--- | :--- | :--- | :--- |
| **1. 跳台阶** (纯粹单向试探) | 我正站在第 `x` 级台阶 | 只有 **2个物理动作**：`dfs(x+1)` 和 `dfs(x+2)` | **不需要！**没有使用全局记事本，参数局部传递，绝不回头。 | `x == n` (成功) 或 `x > n` (撞墙) |
| **2. 子集** (选或不选) | 我正面对着数字 `x` | 只有 **2种主观决策**：选它 (`st[x]=1`)，或不选它 (`st[x]=2`) | **必须恢复！**(`st[x]=0`)。虽然这题特殊可以直接覆盖，但养成习惯，用完全局数组要擦黑板。 | `x > n` |
| **3. 全排列** (填坑模式) | 我正在填第 `x` 个坑 | **n种可能 (引入for循环)**：只要库存里有的数字，全部拿出来试一遍。 | **arr不用恢复**(会被覆盖)。**st必须恢复**(查库存用的，试完必须放回篮子 `st[i]=false`) | `x > n` |
| **4. 组合** (不回头模式) | 我正在填第 `x` 个坑 | **有限种可能 (引入start)**：`for(i=start; i<=n)` 只能拿比前面更大的数字。 | **都不需要！**彻底干掉`st`数组。按顺序拿绝对不会重复，`arr`等待被覆盖即可。 | `x > r` |

 * 你的痛苦：看图能懂，一写代码就废，总想在脑子里把递归的所有支路走完（滑动窗口后遗症）。
 * 你的顿悟：人类的大脑内存跑不了递归树！写 DFS 必须化身**“极度短视的机器人”，只需死死盯住“灵魂三问”**：
   * 我是谁？到终点没？（出口 if）
   * 我眼前能迈哪几条腿？（for 循环或直接调用 dfs）
   * 我退回来时需要擦除全局痕迹吗？（恢复现场）
❌ 误区 2：死记硬背“恢复现场”
 * 你的痛苦：知道要还原，但不知道还原谁，在哪还原。
 * 你的顿悟（极其精彩的发现！）：
   * 被直接覆盖的变量（比如全排列里的 arr[x] = i，或者子集里立刻被重写的 st[x] = 2），不需要还原。
   * 作为条件判断的全局变量（比如全排列里的库存清单 st[i]），由于别的平行宇宙还要查阅它，用完必须还原（st[i] = false）！
❌ 误区 3：全排列 return 后的时空错乱
 * 你的痛苦：在 n=2 时，打印完 1 2 退回 dfs(2)，以为还会继续乱跑。
 * 你的顿悟：明白了函数调用栈的“后进先出”。退回来后，会接着执行恢复现场的代码，然后 for 循环 i++。因为 i 越界（i=3 > n），循环彻底结束，从而丝滑地退回到 dfs(1)。
❌ 误区 4：没有利用数学关系进行“剪枝”
 * 你的痛苦：组合题走到死胡同才发现没萝卜了。
 * 你的顿悟：在 for 循环中加入可行性剪枝条件 i <= n - r + x。通过对比“手里的萝卜”和“剩下的坑”，提前砍掉注定失败的分支，这就是算法竞赛拿满分的关键。

## 核心模板:

### 指数型枚举：

```cpp
#include <iostream>
using namespace std;

const int N = 20;
int n;
int st[N]; // 状态数组：记录每个数字的状态。0: 还没走到它, 1: 选它, 2: 不选它

// dfs(x) 里的参数 x，代表程序当前正准备处理“数字 x”
void dfs(int x) {
    
    // ==========================================
    // 灵魂拷问一：到终点没？（出口条件）
    // ==========================================
    // 我们的任务是处理 1~n 这 n 个数字。
    // 当 x > n 时，说明所有数字的状态都已经打好标签了，此时可以输出结果。
    if (x > n) {
        for (int i = 1; i <= n; i++) {
            if (st[i]) {       // 只打印状态标记为 1（选）的数字
                cout << (st[i] == 2 ? "Y" : "N"); 
            }
        }
        cout << '\n';               // 当前方案输出完毕，换行（空集直接输出空行）
        return;                     // 必须 return，退回到上一层去尝试别的组合
    }

    // ==========================================
    // 灵魂拷问二：眼前有几条路？（分支展开）
    // ==========================================
    // 对于当前的数字 x，只有两种客观处理方式：选，或者不选。

    // 路线 A：决定【选】数字 x
    st[x] = 1;          // 动作 1：在全局数组里记录下 x 的状态为 1
    dfs(x + 1);         // 动作 2：处理完了，去处理下一个数字 x + 1

    // ==========================================
    // 灵魂拷问三：退回时需要恢复现场吗？
    // ==========================================
    st[x] = 0;          // 动作 3：从 dfs(x+1) 退回来后，必须把 x 的状态清零！
                        // 因为我们要准备尝试路线 B（不选 x）了。

    // 路线 B：决定【不选】数字 x
    st[x] = 2;          // 动作 1：在全局数组里记录下 x 的状态为 2
    dfs(x + 1);         // 动作 2：同样去处理下一个数字 x + 1
    
    st[x] = 0;          // 动作 3：再次退回来后，再次把 x 的状态清零。
                        // 这样才能干干净净地退回到处理 x-1 的上一层。
}

int main() {
    cin >> n;
    dfs(1); // 毫无悬念，从数字 1 开始处理
    return 0;
}

```

#### 格雷码变体：
一次只能移动一个，则一分支一定前进，二分支一定后退；

```cpp
#include <iostream>
using namespace std;

const int N = 25;
int st[N];  // 记事本：记录当前每个坑位的状态
int n;      // 坑的总数

// 状态字典：假设 1 代表 'O'，2 代表 'X'
char ch[3] = {'#', 'O', 'X'};

// 参数说明：
// step: 当前在填第几个坑
// rev: 挡位指令（0 代表前进挡，1 代表倒车挡）
void dfs(int step, int rev) {
    // 【安检门 1：成功出口】
    if (step > n) {
        for (int i = 1; i <= n; i++) {
            cout << ch[st[i]]; // 输出当前合法状态（注意题目是否要求空格）
        }
        cout << '\n';
        return;
    }

    // 【核心分支：根据挡位决定出牌顺序】
    if (rev == 0) { 
        // 🚗 收到前进指令 (rev == 0)：顺序出牌 1 -> 2
        
        // 分支 1：出 1。因为是第一条路，给小弟传 0（前进）
        st[step] = 1;
        dfs(step + 1, 0); 
        
        // 分支 2：出 2。因为是第二条路（最后一步），给小弟传 1（倒车）
        st[step] = 2;
        dfs(step + 1, 1); 
    } 
    else {          
        // 🚜 收到倒车指令 (rev == 1)：逆序出牌 2 -> 1
        
        // 分支 1：出 2。因为是第一条路，给小弟传 0（前进）
        st[step] = 2;
        dfs(step + 1, 0); 
        
        // 分支 2：出 1。因为是第二条路（最后一步），给小弟传 1（倒车）
        st[step] = 1;
        dfs(step + 1, 1); 
    }
}

// 在 main 函数中的起步姿势：
// dfs(1, 0); // 从第 1 个坑出发，挂【前进挡】开始！
```

## 组合型剪枝：

在受限的组合型 DFS（选定个数、凑定和）中，所有的剪枝本质上都是解不等式。为了统一标准，我们先严谨定义基础状态参数：

- $n$：总共可供选择的元素范围（比如下标 $1 \dots n$ 或数字 $1 \dots n$）。
    
- $k$：题目要求**必须且恰好**选出的元素个数。
    
- $x$：当前处于第 $x$ 层递归，即**正在挑选第 $x$ 个元素**（说明手里已经挑好了 $x-1$ 个）。
    
- $sum$：当前手里已有元素的**累加和**。
    
- $M$：题目要求的**目标总和**（例如自然数拆分或烤鸡中的总和限制）。
    

以下是组合型 DFS 的三大核心数学剪枝法则：

---

### 一、 数量边界剪枝（控制 `for` 循环上限）

**适用场景**：必须恰好选出 $k$ 个元素，且不能重复选择（组合模型）。

**核心逻辑**：剩余未遍历的元素数量 $\ge$ 还需要挑选的元素数量。

**数学推导**：

1. 当前正在挑选第 $x$ 个，总共需要挑选 $k$ 个。因此**还需要挑选的个数**为：$k - x + 1$。
    
2. 假设当前循环变量枚举到了 $i$，那么从 $i$ 到 $n$ **还剩下的元素个数**为：$n - i + 1$。
    
3. 必须满足：$n - i + 1 \ge k - x + 1$。
    
4. 化简不等式，得到 $i$ 的上限：
    
    $$i \le n - k + x$$
    

**代码表现**：

直接修改 `for` 循环的终止条件，过滤掉无意义的遍历。



```C++
// 优化前：for (int i = sta; i <= n; ++i)
// 优化后：
for (int i = sta; i <= n - k + x; ++i) {
    dfs(x + 1, sum + a[i], i + 1);
}
```

---

### 二、 容量边界剪枝（控制 `sum` 溢出）

**适用场景**：元素皆为正数，且要求和为 $M$（例如自然数拆分）。

**核心逻辑**：当前已有的 $sum$ 加上正在尝试的元素 $i$，不能超过目标值 $M$。

**数学推导**：

1. 已知 $sum + i \le M$。
    
2. 移项得到 $i$ 的上限：$i \le M - sum$。
    

**代码表现**：

这不仅可以写在进入 DFS 前的 `if` 拦截中，更高效的做法是直接限制 `for` 循环的范围。



```C++
// 优化前：for (int i = sta; i <= n; ++i) 内部 if(sum + i > M) continue;
// 优化后：
for (int i = sta; i <= min(n, M - sum); ++i) {
    dfs(x + 1, sum + i, i); // 注意自然数拆分允许重复，所以传 i 而不是 i+1
}
```

---

### 三、 极值预判剪枝（Min-Max Projection）

**适用场景**：规定了挑选个数 $k$，规定了目标和 $M$，且知道每个元素可能的最小值 $MIN$ 和最大值 $MAX$（例如烤鸡）。

**核心逻辑**：利用极值计算理论上的上下界，如果理论极限都无法触碰目标，直接剪枝。

**数学推导**：

设当前还需要挑选的个数为 $rem = k - x + 1$。

1. **下界溢出（全选最小也超标）**：如果剩下的 $rem$ 个数全部取最小值 $MIN$，总和依然大于 $M$，则此分支无解。
    
    $$sum + rem \times MIN > M \implies \text{return}$$
    
2. **上界不足（全选最大也不够）**：如果剩下的 $rem$ 个数全部取最大值 $MAX$，总和依然小于 $M$，则此分支无解。
    
    $$sum + rem \times MAX < M \implies \text{return}$$
    

**代码表现**：

写在 DFS 函数的头部，作为进入新一层递归时的全局预判拦截。


```C++
void dfs(int x, int sum, int sta) {
    // 1. 基础越界拦截
    if (sum > M) return; 

    // 2. 极值预判剪枝
    if (x <= k) { 
        int rem = k - x + 1; 
        if (sum + rem * MIN > M) return; // 剪！
        if (sum + rem * MAX < M) return; // 剪！
    }
    
    // ... 成功出口及 for 循环 ...
}
```

### 终极组合 DFS 剪枝骨架模板

将上述三大纯逻辑剪枝合并，这就是一个达到工业级效率的组合型 DFS 通用模板：



```C++
// 已知常量: n(总数), k(目标个数), M(目标和), MIN(最小值), MAX(最大值)

void dfs(int x, int sum, int sta) {
    // 【阶段 1：容量预判与极值预判】
    if (sum > M) return; 
    if (x <= k) {
        int rem = k - x + 1;
        if (sum + rem * MIN > M) return;
        if (sum + rem * MAX < M) return;
    }

    // 【阶段 2：成功出口结算】
    if (x > k) {
        if (sum == M) {
            ans++; // 记录答案
        }
        return;
    }

    // 【阶段 3：数量预判控制范围】
    // 取 n - k + x 和 M - sum 的交集，确保个数和容量双重合法
    int limit = min(n - k + x, M - sum); 
    
    for (int i = sta; i <= limit; ++i) {
        // 如果题目是取数组元素，这里传 sum + a[i]
        // 如果题目是直接拆分数字，传 sum + i
        dfs(x + 1, sum + a[i], i + 1); 
    }
}
```

### 数独填数(排列型)
数独 DFS 的本质，就是前期用数组记录目标，后期套用全排列模板暴力试错(注意特别检验合法不)。
```cpp
#include <iostream>
#include <cstdlib> // exit(0) 强制下班必备
using namespace std;

const int K = 2; // K 是小包厢的边长。如果题目是 2x2 宫格，K=2；如果是 9x9 经典数独，K=3！
const int MAX_SIZE = K * K; // 整个棋盘的边长

int grid[20][20]; // 物理棋盘

// 坑位名单（降维打击的核心）
int px[100], py[100]; 
int pit_cnt = 0; // 记录总共有几个坑

// 🛡️ 专门查验在 (x, y) 放入数字 val 合不合法
bool check(int x, int y, int val) {
    // 1. 查十字线（同行、同列）
    for (int i = 1; i <= MAX_SIZE; i++) {
        if (grid[x][i] == val) return false; 
        if (grid[i][y] == val) return false; 
    }

    // 2. 查小包厢：精准定位左上角
    int startX = ((x - 1) / K) * K;
    int startY = ((y - 1) / K) * K;
    
    for (int i = 0; i < K; i++) {
        for (int j = 0; j < K; j++) {
            if (grid[startX + i][startY + j] == val) {
                return false; // 拦截！
            }
        }
    }
    return true; // 放行！
}

// 🐕 DFS 狗：专门根据名单填坑
// 参数 step: 当前在填名单上的第几个坑
void dfs(int step) {
    // 【成功出口】
    if (step > pit_cnt) {
        // 打印整个修补好的二维棋盘
        for (int i = 1; i <= MAX_SIZE; i++) {
            for (int j = 1; j <= MAX_SIZE; j++) {
                cout << grid[i][j] << " ";
            }
            cout << '\n';
        }
        exit(0); // 只要一个答案？拿到直接下班！
    }

    // 拿出名单，看看当前要填的坑在真实棋盘的哪个坐标
    int x = px[step];
    int y = py[step];

    // 【核心分支：每种萝卜都试一遍】
    for (int i = 1; i <= MAX_SIZE; i++) {
        
        // 【安检门 2：苛刻的保安查验】
        if (!check(x, y, i)) continue; // 冲突了，直接扔掉这个萝卜试下一个

        // 【打钢印】：坑里填入萝卜
        grid[x][y] = i;

        // 【传参 dfs】：踏向下一个坑
        dfs(step + 1);

        // 【擦钢印 / 毁尸灭迹】：排列型必须还原现场！
        grid[x][y] = 0; 
    }
}

int main() {
    // 读入数据阶段，提前“收集坑位” 就是把你最怕的“二维棋盘满屏幕乱找”，强行【降维打击】成了你闭着眼睛都能写的“一维单排填坑（排列型）
    for (int i = 1; i <= MAX_SIZE; i++) {
        for (int j = 1; j <= MAX_SIZE; j++) {
            cin >> grid[i][j];
            if (grid[i][j] == 0) {
                pit_cnt++;
                px[pit_cnt] = i;
                py[pit_cnt] = j;
            }
        }
    }

    // 放狗！从名单上的第 1 个坑开始填！
    dfs(1);

    return 0;
}
```

## 清零原则：
### `ans` 到底在哪里清零？

你提出的这个问题非常有深度！这其实取决于 **`ans` 在物理世界中扮演的究竟是什么角色**。

我们把题目分成三大类，你看完这三个比喻，这辈子都不会再搞错：

#### 🌍 第一类：多组独立游戏（`while(t--)`）

- **物理意义**：上帝按下了宇宙重启键。每一局游戏都是全新的平行宇宙，互相没有任何关系。
    
- **清零位置**：**必须在 `while` 循环的刚开头清零！**
    



```C++
while(t--) {
    ans = 0;           // 宇宙重启！比分板归零！
    memset(st, 0, ...); // 记忆消除！
    // 读入 n，跑 dfs...
}
```

#### 🏆 第二类：多起点，求“全局历史最高/总和”（打擂台）

- **物理意义**：比如你笔记里写的《观星》（求最大星系大小） 或者求所有城市能到达的总数。`ans` 是一块**“世界吉尼斯纪录排行榜”**或者**“全国总账本”**。
    
- **清零位置**：**绝对不能在 `for` 循环里清零！只在 `main` 最外面初始化一次即可！**
    



```C++
int global_max_ans = 0; // 全国排行榜
for (int i = 1; i <= n; ++i) {
    // 每一个新起点去探索
    dfs(i); 
    // 探索完后，去挑战全国排行榜
    global_max_ans = max(global_max_ans, current_run_score); 
}
cout << global_max_ans;
```

#### ⏱️ 第三类：多起点，求“每个人自己的成绩”

- **物理意义**：比如题目问“每个点出发，最多能走多远？” `ans` 是一块**“个人专属秒表”**。张三跑完测出 100 米，李四起跑前，秒表必须归零，否则李四的成绩就会加上张三的！
    
- **清零位置**：**必须在每次 `dfs` 起跑前，紧贴着 `dfs` 清零！**
    



```C++
for (int i = 1; i <= n; ++i) {
    ans = 0; // 发令枪响前，秒表归零！
    memset(st, 0, ...); // 洗干净鞋底
    dfs(i);
    cout << "第 " << i << " 个人的成绩是：" << ans << '\n';
}
```

**【终极口诀总结】**： 不要死记硬背！每次写 `ans = 0;` 之前，问自己一句：**“这个 `ans`，它是为上一局/上一个人服务的，还是为全人类服务的？”** 为全人类服务（求总和/求全局最值），就不清零；为单局/单人服务，开跑前必清零！

总结：
一句话揭露本质：**参数传状态是为了省去终点结算，二维存答案是为了破解输出顺序的死局。你踩的坑，全是因为新武器刚上手，导致了“逻辑重叠”！**

为你精炼总结这两大杀器及对应误区：

**1. 状态参数化（DFS的第二个参数 `sum`）**

- **精髓**：把“走到当前这一步的累加结果”作为参数传给下一层（`dfs(x+1, sum+i)`）。它像接力棒，到了终点直接就能用，不用重算，也不用写恢复现场。
    
- **你的失误（逻辑重叠）**：你接过了接力棒，但在终点 `if(x > 10)` 里，又习惯性地写了个 `for` 循环重新把数组加了一遍。导致 `sum` 算了两遍，直接爆掉。
    

**2. 收集与输出解耦（二维记事本 `ans[][]`）**

- **精髓**：遇到“先问总数，再看明细”的题，绝对不能在 DFS 里直接 `cout`。必须用 `ans[cnt][i]` 把方案先囤起来，等 DFS 跑完，在 `main` 函数里先打印 `cnt`，再用双重循环打印明细。
    
- **你的失误（逻辑重叠与手误）**：
    
    - 你把 `cnt++` 写在了存数据的 10 次 `for` 循环**里面**，导致一行数据被拆到了 10 行里。正确的做法是：**发现新方案，行数 `cnt` 先加 1，然后再循环填这一行的 10 个列。**
        
    - 外加几个低级手误（常量未加 `const`、变量名 `i/j` 混淆、`<<` 写反），说明大脑在处理新结构时，对基础语法的注意力被分散了。

本题共 $16$ 个测试点，前 $15$ 个每个测试点 $6$ 分，最后一个测试点 $10$ 分。

## 伪代码 ：
 剪枝：数组记录到达每一层的【历史最少步数】（既有状态，又有记录，初值大） ：求最小 就要这样 **剪枝**（保证最小，不然剪枝）；
 出口：有指定终点 所以出口 为等于**指定值 不是最大**；；
	 记录： 最小值；
 分支：要确保合法 迭代的值（**有输入值则改的是 数组【x】，不一定是一**）要判断合法；
 还原：不需要，剪枝的时候return 过了
 
**有输入值则 起跑为 输入，不一定是1

```cpp
#include <bits/stdc++.h>
using namespace std;
const int N = 209;
int k[N];
int n,a,b;
int m_step[N];
int ans = 1e9;

void dfs(int x,int step)
{
	if(step >= m_step[x]) return;
	else m_step[x] = step;
	
	if( x== b)
	{
		ans = min(ans,m_step[x]);
		
		return ;
	}
	
	if(x+k[x] <= n) dfs(x+k[x],step+1);
	if(x-k[x] >= 1) dfs(x-k[x],step+1);
	
	
}

int main()
{
	cin >> n >> a >> b;
	for(int i = 1;i<=n;++i) cin >> k[i],m_step[i] = 1e9;;
	dfs(a,0);
	cout << (ans == 1e9 ? -1 : ans) <<'\n';
	
	return 0;
}
```
