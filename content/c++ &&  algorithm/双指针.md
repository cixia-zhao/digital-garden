# 📖 双指针与滑动窗口终极指南

## 一、 核心哲学：状态增量维护

如果你把区间的左边界和右边界想象成两个指针，这种“固定左端点，右端点不断向右扩张”的做法，就是双指针算法的前置基础。

它的核心哲学就一句话：**“绝不抛弃已经算过的历史数据，把大问题化解为（老本 + 新增变量）。”**

无论题目是求和、计数、还是找特定的字符规律，只要是这种“连续区间”的问题，都可以套用最朴素的增量扩展模板（将 `O(N^3)` 暴力降维到 `O(N^2)`）：



```C++
int ans = 0; // 最终答案

// 1. 外层循环：枚举所有可能的起点 i
for (int i = 0; i < n; ++i) { 
    
    // 【关键】为当前的起点 i 初始化一个干净的“账本”（状态变量）
    int count = 0; 
    int sum = 0;   
    
    // 2. 内层循环：终点 j 从起点 i 开始，像贪吃蛇一样一步步向右吃元素
    for (int j = i; j < n && j <= MAX_LIMIT; ++j) { 
        
        // 【核心操作】增量更新：只把最新吃进来的元素 s[j] 记入账本
        if (check(s[j])) count++; 
        sum += s[j]; 
        
        // 3. 结算区：判断当前区间 [i, j] 的状态是否达到了题目的要求
        int current_len = j - i + 1; // 当前区间的长度
        
        if (current_len >= MIN_LEN && count >= TARGET) {
            ans++; // 记录答案（或者打擂台求 max/min）
        }
        
        // 【防爆零剪枝】如果当前状态已经“彻底无救”，直接 break 掉内层循环提前结束。
    }
}
```

## 二、 进阶选型：双指针的三大核心业务模型

当你在题目中看到要求在 `O(N)` 时间内寻找目标时，立刻对自己发出灵魂拷问：

**“这题找的是连续区间还是非连续序列？窗口长度是死的是活的？”**

根据答案，直接对号入座以下三大模型：

### 🐍 模型一：弹性伸缩窗口（“贪吃蛇”连续模型）

- **雷达特征**：题目问“求最长的满足...”、“求最短的满足...”。明确要求是**连续子数组/子串**，但你不知道目标窗口有多长，只能动态伸缩。
    
- **业务逻辑**：右指针疯狂吃进新元素；一旦吃撑了（触发警报），左指针就必须往右挪，把老元素吐出来，直到账本重新合法。
    
- **填空前必看的灵魂三问**：
    
    1. **账本记什么？**（求和？统计频次？哈希表查重？）
        
    2. **`while` 的警报条件是什么？**（什么时候必须让 `l` 吐出元素？）
        
    3. **算分点在哪？**
        
        - 求**最长** 👉 算在 `while` 外面的下方（安检合格后）。
            
        - 求**最短** 👉 算在 `while` 外面的上方（刚吃进来就达标时）。
            
        - 求**配对/计数** 👉 `while` 里面收库存，`while` 外面算总账。
            



```C++
#include <bits/stdc++.h>
using namespace std;
using ll = long long;

const int N = 5e5 + 9; 
int a[N];              
ll ans = 0;            

int main() {
    ios::sync_with_stdio(0); cin.tie(0); cout.tie(0);
    
    int n; 
    if(cin >> n) {
        for(int i = 1; i <= n; ++i) cin >> a[i]; // 万物从 1 开始
        
        int l = 1; 
        ll window_state = 0; // 【核心账本】：绝对不要定义在 for 循环里！
        
        for (int r = 1; r <= n; ++r) {
            // 步骤 1. 进（充能）：r 踩到了新元素，拉进窗口，记入账本！
            // window_state += a[r];
            
            // ⚠️ 【求“最短/最小”】专属算分点
            // ans = min(ans, r - l + 1); 

            // 步骤 2. 判：触发拉响警报的临界条件（如 window_state > target）
            while( /* 触发收缩的条件 */ ) {
                // 步骤 3. 算：【配对/计数类】专属查库存点
                // if(a[l] == 目标) valid_cnt++;

                // 步骤 4. 出：毁尸灭迹！将 a[l] 的影响从账本中残忍抹去！
                // window_state -= a[l];
                
                l++; // 完成一次收缩
            }
            
            // 步骤 5. 算：外部统计答案
            // ⚠️ 【求“最长/最大”】专属算分点（或者在这里组合配对库存）
            // ans = max(ans, (ll)(r - l + 1));
        }
        cout << ans << '\n';
    }
    return 0;
}
```

### 🚌 模型二：刚性平移窗口（“观光大巴”定长模型）

- **雷达特征**：题目明确规定了“**长度固定为 K** 的连续子数组”、“每次看前面连续 M 个数”。
    
- **业务逻辑**：这是一辆只有 K 个座位的定长观光大巴。**绝对不要写内层的 `while` 循环！** 每次车往前开一个街区，严格执行“前门上一个新人，后门踹下去一个老人”。
    



```C++
#include <bits/stdc++.h>
using namespace std;
using ll = long long;

const int MAXN = 100000 + 9;
int a[MAXN]; 
ll ans = 0; 

int main() {
    ios::sync_with_stdio(0); cin.tie(0); cout.tie(0);
    
    int n, k; 
    if(cin >> n >> k) {
        for(int i = 1; i <= n; ++i) cin >> a[i];
        
        ll window_state = 0; 
        
        // 步骤 1. 首发大巴车充能：先把前 k 个人塞进车里
        for(int i = 1; i <= k; ++i) {
            window_state += a[i]; 
        }
        // ans = max(ans, window_state);
        
        // 步骤 2. 大巴车整体平移：1人上车，必定1人下车
        int l = 1;         // 左指针：指着即将被踹下车的老人
        int r = k + 1;     // 右指针：指着即将上车的新人
        
        while(r <= n) {
            // 进（上车）：新人上车，记入账本
            window_state += a[r];  
            
            // 出（下车）：老人滚蛋，直接抹除！极度干净，没有 while 嵌套！
            window_state -= a[l];  
            
            // 算：更新答案
            // ans = max(ans, window_state);
            
            // 车轮同步往前滚
            l++; 
            r++; 
        }
        cout << ans << '\n';
    }
    return 0;
}
```

### 🎯 模型三：快慢指针（流水线质检 / “渣男找备胎”非连续模型）

- **雷达特征**：题目要求**“找子序列（不连续）”**、“包含匹配”、“在长串里按顺序抠出短串”。
    
- **业务逻辑**：放弃连续区间的执念！
    
    - **快指针 `i`**：无情的流水线传送带（大背景数组），只管一路向右，绝不回头。
        
    - **慢指针 `j`**：手里拿着“目标清单”的质检员（或者“找备胎的渣男”）。他盯着流水线，**只有遇到清单上当前急需的那个目标时，他才“牵手”并往下看下一个目标**；其他废品一律无视，原地死等。
        
- **贪心本质**：“早匹配早超生”。遇到了能配对的绝不放过，不要等后面更好的，占住坑位最重要。
    

```C++
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(0); cin.tie(0); cout.tie(0);
    
    string s, t; // s 是汪洋大海(主串)，t 是目标清单(子串)
    if (cin >> s >> t) {
        s = " " + s; // 万物从 1 开始
        t = " " + t;
        
        int n = s.size() - 1;
        int m = t.size() - 1;
        
        int j = 1;   // 慢指针：目标清单的进度（目前正急需寻找 t[1]）
        int ans = 0; // 成功牵手/匹配的数量
        
        // 快指针 i 像无情的流水线，从左到右扫荡 S
        for (int i = 1; i <= n; ++i) {
            // 【核心安检门】：清单还没找完 (j <= m) 且 流水线上的物品 s[i] 刚好是急需的 t[j]
            if (j <= m && s[i] == t[j]) {
                ans++; // 牵手成功
                j++;   // 清单划掉一项，开始期待下一个目标
            }
        }
        
        cout << ans << '\n';
    }
    return 0;
}
```

```cpp
  int count = 0;

  for(int r = 1;r<=n;++r)

  {

    count += a[r];

    while(count >= s)

    {

      ans = min(ans,r-l+1);

      count -= a[l];

      l++;

    }

  }

  return 0;
```

# P11042 [蓝桥杯 2024 省 Java B] 类斐波那契循环数

## 题目描述

对于一个有 $n$ 位的十进制数 $N = d_1d_2d_3\dots d_n$，可以生成一个类斐波那契数列 $S$，数列 $S$ 的前 $n$ 个数为 $\{S_1=d_1,S_2=d_2,S_3=d_3,\dots,S_n=d_n\}$，数列 $S$ 的第 $k(k>n)$ 个数为 $\sum^{k−1}_{i=k−n} S_i$。如果这个数 $N$ 会出现在对应的类斐波那契数列 $S$ 中，那么 $N$ 就是一个类斐波那契循环数。

例如对于 $197$，对应的数列 $S$ 为 $\{1, 9, 7, 17, 33, 57, 107, 197, \dots \}$，$197$ 出现在 $S$ 中，所以 $197$ 是一个类斐波那契循环数。


请问在 $0$ 至 $10^7$ 中，最大的类斐波那契循环数是多少？

这是一道结果填空的题，你只需要算出结果后提交即可。本题的结果为一个整数，在提交答案时只输出这个整数，填写多余的内容将无法得分。

## 输入格式

本题无输入。

## 输出格式

一行一个整数，表示你算出的答案。

```cpp
#include <bits/stdc++.h>
using namespace std; 
using ll = long long;
ll x;
ll se[100];//注意是数 不是字符串； 
bool check(ll x)
{
	string s = " "+ to_string(x);
	int len = s.size() -1;
	ll wd = 0;
	for(int i = 1;i <= len;++i)
	{
		se[i] = s[i] - '0';//转成数字 ，直接正向取位； 
		wd += se[i];
	}
	ll l = 1;
	ll r = len ;
	
	while(1)
	{
		ll nnum = wd;
		
		if(nnum == x) return true;
		if(nnum > x) return false;
		r++;
		se[r] = nnum;
		wd += se[r];
		wd -= se[l];
		l++;
	}
	
}

int main()
{
	ios::sync_with_stdio(0);cin.tie(0);cout.tie(0);

	{
		if(check(i))

			break;
		}
		
		
	}
	
	
	return 0;
}
```
