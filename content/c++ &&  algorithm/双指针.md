## 状态增量维护

如果你把区间的左边界和右边界想象成两个指针，这种“固定左端点，右端点不断向右扩张”的做法，其实也是大名鼎鼎的滑动窗口和双指针算法的核心前置基础！
它的核心哲学就一句话：“绝不抛弃已经算过的历史数据，把大问题化解为（小问题 + 新增变量）。”

💡 通用核心模板：枚举起点 + 增量扩展
无论题目是求和、计数、还是找特定的字符规律，只要是这种“连续区间”的问题，你都可以套用下面这个模板：
```cpp
int ans = 0; // 最终答案

// 1. 外层循环：枚举所有可能的起点 i
for (int i = 0; i < n; ++i) { 
    
    // 【关键】为当前的起点 i 初始化一个干净的“账本”（状态变量）
    // 注意：这里的账本可以是整型、数组，甚至是一个哈希表（看具体题目需求）
    int count = 0; 
    int sum = 0;   
    
    // 2. 内层循环：终点 j 从起点 i 开始，像贪吃蛇一样一步步向右吃元素
    for (int j = i; j < n && j <= 某个最大边界; ++j) { 
        
        // 【核心操作】增量更新：只把最新吃进来的元素 s[j] 记入账本
        if (满足某种条件(s[j])) {
            count++; 
        }
        sum += s[j]; 
        
        // 3. 结算区：判断当前区间 [i, j] 的状态是否达到了题目的要求
        int current_len = j - i + 1; // 当前区间的长度
        
        // 如果满足条件（比如长度达标、或者和大于某个值）
        if (current_len >= 最小要求 && count >= 标准) {
            ans++; // 记录答案（或者打擂台求 max/min）
        }
        
        // 【注意】如果当前状态已经“彻底无救”了（比如要求全都是数字，但碰到了字母），
        // 可以直接 break 掉内层循环，提前结束这个起点 i 的探索（剪枝优化）。
    }
}
```

🎯 什么时候用？（出现这些“题眼”立刻触发警报）
当你在题目中看到以下几个特征组合出现时，脑子里就应该立刻弹出这个“贪吃蛇增量”模板：
1. 关键词：“子数组”或“子串”
只要题目强调是连续的一段元素，必然涉及到区间的起点和终点，这通常是这套模板的绝对主场。如果题目说是“子序列”（可以不连续），那这套模板就不适用了，通常要考虑动态规划（DP）。
2. 状态具有“可累加性”或“延续性”
你在思考暴力解法时发现：区间 [i, j] 的结果，可以由区间 [i, j-1] 的结果顺手加上第 j 个元素直接得到。比如：
 * 统计区间内某个字母的个数。
 * 求区间元素的和。
 * 记录区间内出现过哪些不同的数字。
3. 数据范围卡在 10^3 到 10^4 之间
如果原数组长度 N 大概在几千左右，标准的 O(N^3) 暴力破解绝对会超时（Time Limit Exceeded）。你需要把时间复杂度降维到 O(N^2)。这套模板正好是 O(N^2) 的。


## 快慢指针（滑动窗口）模版

一句话揭露本质：武林秘籍最忌讳心法杂糅！我帮你把这两套模板的“雷达预警”和“核心心法”重新梳理，按照“先看病（看特征），再抓药（套模板）”的清晰逻辑进行了完美缝合。
描述性废话全部砍掉，只留能在考场上救命的纯干货。代码块和你的宝贝注释原封不动。直接把这份**【滑动窗口终极缝合版】**替换掉你笔记里的旧内容：
📦 终极兵器库：滑动窗口（双指针）双门派模板
在遇到要求在 O(N) 时间内寻找**“连续子区间 / 子串”的题目时，立刻对自己发出灵魂拷问：“这题的窗口长度，是个定数，还是个变数？”**
根据答案，直接对号入座以下两大门派：
⚔️ 门派一：弹性伸缩派（虫子爬行 / 长度可变）
 * 🚩 雷达特征：题目问“求最长的满足...”、“求最短的满足...”、“满足某种配对的组合数量”。你根本不知道目标窗口有多长，只能动态伸缩。
 * 💡 核心心法（填空前必看的灵魂三问）：
   * 账本记什么？（和？个数？哈希表查重？）
   * while 的警报条件是什么？（什么时候必须让 l 往右跑来吐出元素？）
   * 我是哪种情况（A/B/C），该在哪算答案？
     * 求最长 👉 算在 while 外面下面（情况 A）。
     * 求最短 👉 算在 while 外面上面（情况 B）。
     * 数组合/配对 👉 while 里面收库存，while 外面算总账（情况 C）。

```cpp
#include <bits/stdc++.h>
using namespace std;
using ll = long long;

// ================= 全局变量区 =================
const int N = 5e5 + 9; // 万物从 1 开始，根据题目要求开满空间
int a[N];              // 原数组（或 string s）
ll ans = 0;            // 最终答案（打擂台或计数，强行养成用 ll 的好习惯）

int main()
{
    // 极致的 I/O 加速
    ios::sync_with_stdio(0); cin.tie(0); cout.tie(0);
    
    int n; 
    if(cin >> n) 
    {
        for(int i = 1; i <= n; ++i) cin >> a[i];
        
        int l = 1; // 左指针老老实实从 1 开始，绝不乱动
        
        // 【核心账本】：用于记录窗口 [l, r] 内的特征（比如和、某种字符的数量等）
        // 绝对不要把这个账本定义在 for 循环里面！
        ll window_state = 0; 
        
        // 右指针 r 像贪吃蛇一样，从 1 开始一步步向右吞噬新元素
        for (int r = 1; r <= n; ++r) 
        {
            // ==========================================
            // 步骤 1. 进（充能）：r 踩到了新元素，强行拉进窗口，记入账本！
            // [填写区] 例如：window_state += a[r];
            // ==========================================
            

            // ⚠️⚠️ 【情况 B：求“最短 / 最小”合法区间】专属算分点 ⚠️⚠️
            // 如果题目求最短，走到这里说明刚刚吃进来的 r 可能让窗口达标了。
            // 趁着还没进 while 吐出元素，先用 ans = min(ans, r - l + 1); 记录一下！
            

            // ==========================================
            // 步骤 2. 判：触发拉响警报的临界条件（安检门）
            // 什么时候必须收缩窗口？比如和超标了、遇到重复字符了、距离够长了
            // ==========================================
            while( /* [填写区] 触发收缩的条件，例如 window_state > target 或 r - l + 1 >= k */ ) 
            {
                // 步骤 3. 算（内部状态更新 / 计数类特供）：
                // ⚠️⚠️ 【情况 C：配提 / 计数类】专属查库存点 ⚠️⚠️
                // 这是 l 滚出窗口前的“毕业安检”：看看 l 踩到的是不是我们要的特征？
                // [填写区] 例如：if(a[l] == 目标) valid_cnt++;
                

                // 步骤 4. 出：毁尸灭迹！将 a[l] 的影响从账本中残忍抹去！
                // [填写区] 例如：window_state -= a[l];
                
                
                // 左指针 l 往前挪一步，完成一次收缩（这一步死都不能删）
                l++;
            }
            
            // ==========================================
            // 步骤 5. 算（外部统计答案）：
            // ==========================================
            
            // ⚠️⚠️ 【情况 A：求“最长 / 最大”合法区间】专属算分点 ⚠️⚠️
            // 因为 while 循环就像个清洁工，把所有“不合法”的都吐掉了。
            // 能活着走到这一行的窗口 [l, r] 绝对是合法的！
            // [填写区] 例如：ans = max(ans, (ll)(r - l + 1));
            
            
            // ⚠️⚠️ 【情况 C：配对 / 计数类】专属算分点 ⚠️⚠️
            // 此时 r 踩到了目标元素，直接和内部 while 收集到的合法库存进行组合结算！
            // [填写区] 例如：if(a[r] == 目标2) ans += valid_cnt;

        }
        
        cout << ans << '\n';
    }
    return 0;
}
```
🚌 门派二：刚性大巴派（整体平移 / 长度固定）
 * 🚩 雷达特征：题目明确规定了**“长度固定为 K 的连续子数组”、“长度为 N 的子串”、“每次看前面连续 M 个数”**。
 * 💡 核心心法：绝对不要写内层的 while 循环！ 长度死死锁定，永远是先用 for 把前 K 个人搞定，然后开一个 while(r <= n)。每次严格执行“新上车一个，老下车一个，两边同步往前滚”。

```cpp
#include <bits/stdc++.h>
using namespace std;
using ll = long long;

const int MAXN = 100000 + 9;
int a[MAXN]; 
ll ans = 0; // 记录极值或数量

int main()
{
    ios::sync_with_stdio(0); cin.tie(0); cout.tie(0);
    
    int n, k; // n 是总长度，k 是题目要求的大巴车固定长度（如找长度为 3 的和）
    if(cin >> n >> k) 
    {
        for(int i = 1; i <= n; ++i) cin >> a[i];
        
        ll window_state = 0; // 核心账本（如：窗口内元素的和）
        
        // ==========================================
        // 步骤 1. 首发大巴车充能：先把前 k 个人塞进车里
        // ==========================================
        for(int i = 1; i <= k; ++i) 
        {
            window_state += a[i]; // 账本记录初始状态
        }
        
        // 记录首发大巴车的成绩（视题目要求：可能在这里更新 ans）
        // ans = max(ans, window_state);
        
        // ==========================================
        // 步骤 2. 大巴车整体平移：1人上车，必定1人下车
        // ==========================================
        int l = 1;         // 左指针：一开始指着被踢下车的第 1 个人
        int r = k + 1;     // 右指针：一开始指着即将上车的第 k+1 个人
        
        while(r <= n) // 只要大巴车还没开到终点
        {
            // 进（上车）：右边的新人上车，影响记入账本
            window_state += a[r];  
            
            // 出（下车）：左边的老人滚蛋，从账本里抹除！
            // ⚠️ 极其干净：没有任何 while 循环，直接一进一出！
            window_state -= a[l];  
            
            // 算：更新答案（此时窗口 [l+1, r] 刚好又恢复成了长度 k）
            // [填写区] 例如：ans = max(ans, window_state);
            
            // 车轮同步往前滚：左边右边同时迈步！
            l++; 
            r++; 
        }
        
        cout << ans << '\n';
    }
    return 0;
}
```

```cpp
#include <bits/stdc++.h>

using namespace std;

const int N = 1e6+9;

char s[N];

int main()

{

  ios::sync_with_stdio(0),cin.tie(0),cout.tie(0);

  int l = 1,r = n;

  while(l<r && ans)

  }
```

快慢指针（滑动窗口）例题：

![[Pasted image 20260311172137.png]]


```cpp
#include <bits/stdc++.h>

using namespace std;

const int N = 1e5+9;

int a[N]; 

int main()

{
  ios::sync_with_stdio(0),cin.tie(0),cout.tie(0);
  int n,s;cin >> n >> s;

  int l =1;

  int ans = n+1;

  for(int i = 1;i <= n;++i) cin >> a[i];

  int count = 0;

  for(int r = 1;r<=n;++r)

  {

    count += a[r];

    while(count >= s)

    {

      ans = min(ans,r-l+1);

      count -= a[l];

      l++;

    }

  }

  cout << (ans <= n ? ans : 0) <<'\n'; 

  return 0;

}
```

```cpp
    }

      }

    }

  }
```
