# 🧠 核心概念/问题 (Concept / Problem)

> 无法理解为什么交换函数直接传失败了，而加法就可以？

---

# 💡 我的思考与解决方案 (My Thoughts & Solution)

> · 传值：我给你一本小说的复印本，你在上面做了笔记。我手里的原版小说不受影响。
· 传引用：我给你我家地址的钥匙，你直接来我家在原版小说上做笔记。
### 错误尝试 (如果适用)

> 一开始不知道实际上 直接传相当于 int a = x,只是把x值赋给a。所以根本改变不了。
> 

### 正确路径 / 关键代码

```cpp

void swap(int &a, int &b) {  // a是x的别名，b是y的别名
    int temp = a;  // 操作的就是x本身！
    a = b;         // x = y
    b = temp;      // y = 原来的x
}




```

# 🎯 给未来自己的话（一句话总结）

> 记住引用的作用,以及,正常传实际上就是把值赋给他,改变的是复印件，而不是本体。加上引用，就是取别名，int &a = x。这个时候就能同时对他造成改变了。
