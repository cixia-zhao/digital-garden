### 🎯 核心功能 (Purpose)
> 
> ![[Screenshot_2026-02-25-21-32-22-26_149003a2d400f6adb210d7e357a3a646.jpg]]
快慢指针可以使得时间复杂度，从 O (n²)变成 O(n)。
### ✍️ 标准语法 (Syntax)
```cpp
int j = 0;
// 为了逻辑更清晰，我们换一种更常见的快慢指针写法
// i 是快指针，j 是慢指针
for (int i = 1; i < n; ++i) {
    if (arr[i] != arr[j]) { // 如果当前元素和新数组的最后一个元素不同
        j++;             // 慢指针移动
        arr[j] = arr[i]; // 将新元素写入
    }
}
// 最终去重后的数组长度是 j + 1
```
