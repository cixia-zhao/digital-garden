## 建账本（哈希桶）时，数组大小 `[ ]` 看的是“有几种东西”（一般做统计字符出现频率是 300），数组类型（`int` 或 `long long`）看的是“同一种东西最多有多少个”！所以一般题目数据范围决定的是数据类型，[]里面一般会说明个数；


## 生死攸关的 `&` 符号（传值 vs 传引用）

你之所以在 DFS 里没用过 `&`，是因为你习惯了**直接“毁尸灭迹”修改全局数组**，或者为了**保持纯洁的局部状态去回溯**。但只要你单独写了一个外包函数，就必须严守以下规矩：

- **【坚决不加 `&`】：传复印件保平安。** * _场景：_ DFS 里的状态传参（如 `dfs(x+1, sum+val)`）。
    
    - _原因：_ 去下一层探路如果撞死在“安检门”，退回来时当前的 `sum` 必须是干净的。加了 `&` 会导致回溯彻底报废！判断闰年等只用来看一眼的函数，也不加。
        
- **【必须加 `&`】：拿大门钥匙“毁尸灭迹”。**
    
    - _场景：_ 你写了独立的 `void f(char &c)`、`swap(int &a, int &b)` 这种想要修改传入值的真实数据的外包函数。
        
    - _原因：_ 不加 `&`，C++ 只会把变量当成纸质复印件传进去，你在函数里改出花来，原本的“坑”和“萝卜”原封不动（这就是你硬币题输出 2 的真凶）。

## 贪心模型：对称差值

### 🎯 触发雷达

1. **目标**：把数组变成“回文”（左半边和右半边一模一样，即 $a_i = a_{n-i+1}$）。
    
2. **武器**：可以改 1 个数（单买），也可以**同时改相邻的 2 个数**（买一送一）。
    
3. **所求**：最少的操作次数。
    


---

### 为什么只看左半边？

回文是镜像对称的，左边拉长，右边就相当于缩短。我们只需要死死盯住**左半边（1 到 n/2）**。

如果我们在脑子里凭空想原数组，很容易晕。所以我们建一个“差距账本”：

👉 **`diff[i] = a[i] - a[n-i+1]` （左边的萝卜 减去 右边对称的萝卜）**

题目的终极目标瞬间被降维：**用最少的步数，把 `diff` 账本里的数字全部变成 0！**

---

### 🎬 物理透视：代码操作 vs 原数组的真实形变

我们用一个真实的案发现场，同步直播“改账本”时，“原数组”到底发生了什么变异。

**📌 初始案发现场**

原数组：`a = [6, 4, 1, 2]` （共 4 个萝卜）。

只看左半段（第 1 和第 2 个坑），初始化账本：

- 第 1 坑：`diff[1] = 6 - 2 = 4`
    
- 第 2 坑：`diff[2] = 4 - 1 = 3`
    
    当前账本：**`diff = [4, 3]`**
    

我们要从左到右，把这个账本清零：

#### ⚡ 动作一：触发“买一送一”（相邻修改组合技）

我们在账本上看到，第 1 坑差 4，第 2 坑差 3。它们都需要做减法（同为正数）。

- **💻 代码指令**：
    

    ```C++
    int share = min(diff[1], diff[2]); // share = 3 (最多白嫖 3 次)
    ans += 3;       // 老板结账，付 3 块钱
    diff[1] -= 3;   // 账本变动：4 - 3 = 1
    diff[2] -= 3;   // 账本变动：3 - 3 = 0
    ```
    
- **🌍 原数组物理形变（真相）**：
    
    代码在账本上减了 3，对应的物理动作是：**你跑进地里，把 `a[1]` 和 `a[2]` 两个萝卜同时砍掉了 3 截！**
    
    原数组从 `[6, 4, 1, 2]`
    
    变成了 👉 `[6-3, 4-3, 1, 2]` = **`[3, 1, 1, 2]`**！
    
    _(验算：此时左边是 `3, 1`，右边是 `2, 1`。第 2 个坑的 `1` 和右边的 `1` 已经完美对齐了！账本 `diff[2]=0` 诚不欺我！)_
    

#### ⚡ 动作二：清理尾款（单点修改）

刚才白嫖完，账本变成了 `diff = [1, 0]`。第 1 个坑还残留了 `1` 的差距。右边已经是 0 了，没法再白嫖了。

- **💻 代码指令**：

    ```C++
    ans += diff[1]; // ans += 1 （没折扣了，老老实实付全款）
    diff[1] = 0;    // 账本强行清零
    ```
    
- **🌍 原数组物理形变（真相）**：
    
    代码结算残留，对应的物理动作是：**你跑进地里，单独把 `a[1]` 这个萝卜又砍掉了 1 截！**
    
    原数组从 `[3, 1, 1, 2]`
    
    变成了 👉 `[3-1, 1, 1, 2]` = **`[2, 1, 1, 2]`**！
    
    _(验算：左边 `2, 1`，右边 `2, 1`。全剧终！数组完美变成回文！)_
    

总共花了多少钱？`ans = 3 + 1 = 4` 次操作。
### 模板：

```cpp
#include <bits/stdc++.h>
using namespace std;

// 1. 万物乘积超 21 亿，必须开 long long 保平安！
// 极端情况下，每个坑 200万差距，5万个坑全不靠边，总和千亿级别，int 必死。
using ll = long long; 

const int N = 100005;
int a[N];
int diff_arr[N]; // 专属账本：对称差值数组

int main()
{
    // 2. 极致的 I/O 加速
    ios::sync_with_stdio(0); cin.tie(0); cout.tie(0);
    
    int n;
    if(cin >> n)
    {
        // 3. 叫醒保安：万物从 1 开始录入
        for(int i = 1; i <= n; ++i) cin >> a[i]; 
        
        int m = n / 2; // 回文只看左半边即可
        
        // 4. 建立对称差值账本（左边减右边）
        for(int i = 1; i <= m; ++i)
        {
            diff_arr[i] = a[i] - a[n - i + 1];
        }
        
        ll ans = 0; // 记录总共花了多少钱（操作次数）
        
        // 5. 从左到右无情扫荡
        for(int i = 1; i <= m; ++i)
        {
            // ============ 情况 A：需要做减法的（正数） ============
            if(diff_arr[i] > 0) 
            {
                // 【安检门】：右边兄弟也是正数？触发买一送一！
                if(i < m && diff_arr[i+1] > 0)
                {
                    // 白嫖的次数，取决于谁的余额少
                    int share = min(diff_arr[i], diff_arr[i+1]);
                    ans += share; // 先把打折的钱付了
                    
                    // 物理形变：原数组 a[i] 和 a[i+1] 同时变小
                    diff_arr[i] -= share;
                    diff_arr[i+1] -= share;
                }
                
                // ⚠️ 极其致命：这里绝对不能写 else！
                // 不管上面有没有白嫖，只要现在还有残留，就得全款单买补齐！
                ans += diff_arr[i]; 
                
                // 物理形变：原数组 a[i] 单独变小，与右边彻底对称！
                diff_arr[i] = 0; 
            }
            
            // ============ 情况 B：需要做加法的（负数） ============
            else if(diff_arr[i] < 0)
            {
                // 【安检门】：右边兄弟也是负数？触发买一送一！
                if(i < m && diff_arr[i+1] < 0)
                {
                    // 负数比大小必须加负号，计算绝对值的 min
                    int share = min(-diff_arr[i], -diff_arr[i+1]);
                    ans += share; // 付钱
                    
                    // 物理形变：原数组 a[i] 和 a[i+1] 同时变大！（向 0 靠拢）
                    diff_arr[i] += share; 
                    diff_arr[i+1] += share;
                }
                
                // 物理形变：原数组 a[i] 单独变大，与右边彻底对称！
                ans += -diff_arr[i]; // 残留尾款
                diff_arr[i] = 0; 
            }
        }
        
        cout << ans << '\n';
    }
    
    return 0;
}
```

## 贪心匹配

### 🎯 概念
当你觉得贪心很抽象，又发现滑动窗口套不上（因为不是在同一个字符串里找连续区间）时，请立刻切换到这个模型。
这题的本质是：**为了让目标 $T$ 的前缀尽可能长地出现在大背景 $S$ 里，一旦在 $S$ 中看到了 $T$ 当前需要的那个字符，就必须立刻“原地结婚”，绝不犹豫！**

- **贪心证明（早匹配早超生）**：如果你不选当前的 $S[i]$ 匹配 $T[j]$，想等后面再匹配，这绝不会让结果变好，反而会浪费当前宝贵的字符坑位。

### 🚩 雷达预警（何时触发此模板）
1. **关键词**：“子序列包含”、“匹配进度”。（注意：子序列可以不连续，只要保持先后顺序即可）。
2. **场景特征**：给两个字符串/数组，一个负责当长长的“主战场”，另一个负责当你要按顺序寻找的“目标清单”。

### 💡 核心心法与防爆零指南
- **快指针 `i`**：遍历主字符串 S 的进度条。必须放在 `for` 循环里，一路向右扫，绝不回头。
- **慢指针 `j`**：当前在目标字符串 T 里的进度。只有“牵手成功”时才 `j++`，否则原地死等。
- **致命安检门**：在做 `s[i] == t[j]` 的判断前，一定要加上 `j <= m`（目标清单还没找完），防止越界查到乱码。

### 💻 专属 C++ 模板

```cpp
#include <bits/stdc++.h>
using namespace std;

int main()
{
	// 1. 极致的 I/O 加速
	ios::sync_with_stdio(0); cin.tie(0); cout.tie(0);
	
	string s, t;
	if (cin >> s >> t)
	{
		// 2. 万物从 1 开始（绝对的防越界信仰）
		s = " " + s;
		t = " " + t;
		
		int n = s.size() - 1;
		int m = t.size() - 1;
		
		int j = 1; // 慢指针：目标 T 的匹配进度（目前正急需第 1 个字符）
		int ans = 0; // 成功匹配的字符数量
		
		// 3. 快指针 i 像无情的流水线一样，从左到右扫荡 S
		for (int i = 1; i <= n; ++i)
		{
			// 【安检门】：目标还没找完 (j <= m) 且 当前流水线上的物品 s[i] 正是我们要的 t[j]！
			if (j <= m && s[i] == t[j])
			{
				ans++; // 牵手成功，答案 +1
				j++;   // T 的进度推进一步，准备查收下一个目标
			}
		}
		
		// 4. 成功出口：扫荡完毕，输出战果
		cout << ans << '\n';
	}
	
	return 0;
}
```



# P8739 [蓝桥杯 2020 国 C] 重复字符串

## 题目描述

如果一个字符串 $S$ 恰好可以由某个字符串重复 $K$ 次得到，我们就称 $S$ 是 $K$ 次重复字符串。例如 `abcabcabc` 可以看作是 `abc` 重复 $3$ 次得到，所以 `abcabcabc` 是 $3$ 次重复字符串。

同理 `aaaaaa` 既是 $2$ 次重复字符串、又是 $3$ 次重复字符串和 $6$ 次重复字符串。

现在给定一个字符串 $S$，请你计算最少要修改其中几个字符，可以使 $S$ 变为一个 $K$ 次字符串？

## 输入格式

输入第一行包含一个整数 $K$。

第二行包含一个只含小写字母的字符串 $S$。

## 输出格式

输出一个整数代表答案。如果 $S$ 无法修改成 $K$ 次重复字符串，输出 $−1$。

## 输入输出样例 #1

### 输入 #1

```
2
aabbaa
```

### 输出 #1

```
2
```

## 说明/提示

其中，$1 \le K \le 10^5$，$1 \le |S| \le 10^5$。其中 $|S|$ 表示 $S$ 的 长度。

蓝桥杯 2020 年国赛 C 组 G 题。
```cpp
#include <bits/stdc++.h>
using namespace std;
using ll = long long;

int ans;

int main()
{
	ios::sync_with_stdio(0);cin.tie(0);cout.tie(0);
	int k;cin >> k;
	string s;cin >> s;
	s = " "+ s;
	int n = s.size()-1;
	int len = n / k;//分段 
	if(n % k != 0) 
	{
		cout << -1 <<'\n';
		return 0;
	}
	
	for(int i = 1;i <= len;++i)//每段第一个 相 
	{
		int bkt[300] = {0};//贪心：找到每一列出现最多的次数；然后 减去它 就是 最小修改；
		// 注意bkt 是统计每一列 所以在外循环里面； 
		int p = 0;
		for(int j = i;j <= n;j+=len) //等差 遍历 起点为 i,配合外循环 当于一列一列 ；
		{							// abb
									// abb 
			bkt[s[j]]++;
			p = max(p,bkt[s[j]]);
			
		}
		ans += (k - p); //每一列的修改次数 = 每一列字母数（总份数） - 每一列所以在里面 
		
	}
	cout << ans <<'\n';
	

	return 0;
}
```

# P10902 [蓝桥杯 2024 省 C] 回文数组

## 题目描述

小蓝在无聊时随机生成了一个长度为 $n$ 的整数数组，数组中的第 $i$ 个数为 $a_i$，他觉得随机生成的数组不太美观，想把它变成回文数组，也是就对于任意 $i\in [1,n]$ 满足 $a_i=a_{n-i+1}$。小蓝一次操作可以指定相邻的两个数，将它们一起加 $1$ 或减 $1$；也可以只指定一个数加 $1$ 或减 $1$，请问他最少需要操作多少次能把这个数组变成回文数组？

## 输入格式

输入的第一行包含一个正整数 $n$。

第二行包含 $n$ 个整数 $a_1, a_2,\cdots, a_n$，相邻整数之间使用一个空格分隔。

## 输出格式

输出一行包含一个整数表示答案。

## 输入输出样例 #1

### 输入 #1

```
4
1 2 3 4
```

### 输出 #1

```
3
```

## 说明/提示

**【样例说明】**

第一次操作将 $a_1, a_2$ 加 $1$，变为 $2, 3, 3, 4$；

后面两次操作将 $a_1$ 加 $1$，变为 $4,3,3,4$。

**【评测用例规模与约定】**

对于 $20\%$ 的评测用例，$1 \le n \le 10$；  
对于所有评测用例，$1 \le n \le 10^5$，$-10^6 \le a_i \le 10^6$。

```cpp
#include <bits/stdc++.h>
using namespace std;

using ll = long long;
ll n;
int a[1000000];
int d[1000000]; 
ll ans;

int main()
{
	ios::sync_with_stdio(0);cin.tie(0);cout.tie(0);
	cin >> n;
	for(int i = 1;i <= n;++i)
	{
		cin >> a[i];
	}
	int m = n / 2;
	for(int i = 1;i <= m;++i)
	{
		d[i] = a[i] - a[n-i+1];
	}
	for(int i = 1;i <= m;++i)
	{
		ll cost = 0;
		if(d[i] > 0 )
		{
			if(i < m && d[i+1] > 0)
			{
				cost = min(d[i],d[i+1]);
				ans += cost;
				d[i] -= cost;
				d[i+1] -= cost;
			}
			ans += d[i];
			d[i] == 0;
		}
		else if(d[i] < 0 )
		{
			if(i < m && d[i+1] < 0)
			{
				cost = min(-d[i],-d[i+1]);
				ans += cost;
				d[i] += cost;
				d[i+1] += cost;
			}
			ans += -d[i];
			d[i] == 0;
		}
		
	}
	
	
		cout << ans <<'\n';
	
	return 0;
}
```

# P10910 [蓝桥杯 2024 国 B] 最小字符串

## 题目描述

给定一个长度为 $N$ 且只包含小写字母的字符串 $S$，和 $M$ 个小写字母 $c_1, c_2, \cdots, c_M$。现在你要把 $M$ 个小写字母全部插入到字符串 $S$ 中，每个小写字母都可以插入到任意位置。

请问能得到的字典序最小的字符串是什么？

## 输入格式

第一行包含两个整数 $N$ 和 $M$。

# P12173 [蓝桥杯 2025 省 Python B] 最多次数

## 题目描述

小蓝有一个字符串 $s$，他特别喜欢由以下三个字符组成的单词：$\tt {l}, \tt{q}, \tt{b}$，任意顺序都可以，一共有 $6$ 种可能：$\tt{lqb}$、$\tt{lbq}$、$\tt{qlb}$、$\tt{qbl}$、$\tt{blq}$、$\tt{bql}$。

现在他想从 $s$ 中，尽可能切割出多个他喜欢的单词，请问最多能切割出多少个？单词指的是由若干个连续的字符组成的子字符串。

## 输入格式

输入一行包含一个字符串 $s$。

## 输出格式

输出一行包含一个整数表示答案。

## 输入输出样例 #1

### 输入 #1

```

```

### 输出 #1

```
3
```

## 说明/提示

### 评测用例规模与约定

- 对于 $20\%$ 的评测用例，$1 \leq |s| \leq 10$；
- 对于 $40\%$ 的评测用例，$1 \leq |s| \leq 20$；
- 对于 $60\%$ 的评测用例，$1 \leq |s| \leq 100$；
- 对于 $70\%$ 的评测用例，$1 \leq |s| \leq 10^3$；
- 对于 $80\%$ 的评测用例，$1 \leq |s| \leq 10^4$；

```cpp
#include <bits/stdc++.h>

using ll = long long;



int main()
{
	ios::sync_with_stdio(0);cin.tie(0);cout.tie(0);
	string s;
	cin >> s;
	s = " "+s;
	int n = s.size()-1;
	ll ans = 0;
	int i = 1;
	while(i <= n-2)//边界注意 要保证最后有三个 
	{
		ll bkt[100000+9] = {0};

		bkt[s[i+1]]++;

		{

		}

		{
			i++;
		}
		
		
	}

}
```
