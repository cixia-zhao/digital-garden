莱布尼茨公式

莱布尼茨公式是微积分中一个重要的高阶导数计算公式，它将函数乘积的求导法则推广到了任意 n 阶导数的情况。该公式揭示了两个函数乘积的高阶导数与这两个函数各自的高阶导数之间的关系，其形式与二项式定理高度相似。

设函数 u=u(x) 和 v=v(x) 均 n 阶可导，则它们的乘积 uv 的 n 阶导数可以表示为：

(uv)(n)=k=0∑n​Cnk​u(n−k)v(k)

其中，u(k) 和 v(k) 分别表示函数 u 和 v 的 k 阶导数（u(0)=u），而 Cnk​ 为二项式系数，即 Cnk​=k!(n−k)!n!​。

罗尔定理

罗尔定理是微分学中的一个基本存在性定理。它直观地描述了一个光滑连续的函数，如果其在两个不同点的函数值相等，那么在这两点之间，函数图像上必然存在至少一个点的切线是水平的，即该点的导数为零。

该定理是连接函数值与导数值的桥梁，其严格数学表述为：

如果函数 f(x) 满足以下三个条件：

  1. 在闭区间 [a,b] 上连续；
  2. 在开区间 (a,b) 内可导；
  3. 在区间端点处的函数值相等，即 f(a)=f(b)。

那么，在 (a,b) 内至少存在一个点 c，使得该点的导数为零：

f′(c)=0

核心应用：证明方程根的存在性

罗尔定理最主要和直接的应用，就是证明一个方程在某个区间内必然有根，特别是对于那些无法直接求解的复杂方程。其解题策略不是直接应用，而是巧妙地进行“逆向工程”。

具体步骤如下：

  1. 目标转换：要证明方程 g(x)=0 在区间 (a,b) 内有根。
  2. 构造辅助函数：这是解题的关键。我们需要构造一个辅助函数 F(x)，使其满足罗尔定理的三个条件。这个函数必须具备两个特性：
    • 它的导数 F′(x) 与目标表达式 g(x) 密切相关，通常是 F′(x) 的一个因子。
    • 它在区间端点 a 和 b 处的函数值相等，即 F(a)=F(b)。寻找满足此条件的点 a 和 b 是解题的突破口。
  3. 应用定理：一旦找到了这样的辅助函数 F(x)，并验证了其连续性和可导性，我们就可以根据罗尔定理断定：必然存在一个 c∈(a,b) 使得 F′(c)=0。
  4. 得出结论：由 F′(c)=0 这个等式，我们就能反推出 g(c)=0，从而证明了方程 g(x)=0 在该区间内至少有一个根。

因此，罗尔定理提供了一种有力的理论工具，它能通过构造一个满足特定条件的函数，来保证其导函数的零点的存在性。

解题步骤

  1. 直接看到最终式子，把最终式子移过去，变成一个新函数。
  2. 找到新函数的原函数，利用构造函数技巧。
  3. 再结合条件应用罗尔定理证明导数为零。

构造函数技巧

拉格朗日中值定理

拉格朗日中值定理，又称均值定理，是微分学理论的基石之一。它深刻地揭示了函数在一个区间上的整体变化（平均变化率）与其内部某一点的局部变化（瞬时变化率）之间的内在联系。几何上，它保证了一条光滑连续曲线上，必有一点的切线平行于连接两端点的割线。

该定理的数学表述如下：

如果函数 f(x) 满足以下两个条件：

  1. 在闭区间 [a,b] 上连续；
  2. 在开区间 (a,b) 内可导。

那么，在 (a,b) 内至少存在一个点 c，使得：

f′(c)=b−af(b)−f(a)​

这个公式也可以写成更利于应用的形式：f(b)−f(a)=f′(c)(b−a)。

主要应用

拉格朗日中值定理的作用不是直接求解，而是作为一种强大的理论工具，用于推导和证明。

1. 证明不等式 这是拉格朗日中值定理最灵活、最常见的应用。基本思路是“构造函数，利用导数”。当需要证明一个涉及函数值的复杂不等式时，可以将其变形为一个形如 f(b)−f(a) 的表达式，然后对构造的函数 f(x) 应用中值定理。问题就转化为研究其导函数 f′(x) 在对应区间上的值域，通过确定导数的上界或下界，来为原不等式提供证明。

2. 讨论函数的单调性 拉格朗日中值定理是严格证明“导数正负决定函数单调性”的理论基础。对于区间内任意两点 x1​<x2​，存在一点 c 使得 f(x2​)−f(x1​)=f′(c)(x2​−x1​)。由于 (x2​−x1​) 恒为正，因此函数值差 f(x2​)−f(x1​) 的符号完全取决于导数 f′(c) 的符号。这直接导出了以下重要结论：

  • 若区间内 f′(x)>0，则函数严格单调递增。
  • 若区间内 f′(x)<0，则函数严格单调递减。
  • 若区间内 f′(x)=0，则函数为常数。

3. 估算与近似计算 通过公式 f(b)=f(a)+f′(c)(b−a)，我们可以利用函数在 a 点的值和导数在某点的值来估算在 b 点的函数值。这是泰勒公式的最初始、最简单的形式，为函数的近似展开提供了理论依据。

总而言之，拉格朗日中值定理是连接函数与导数的万能桥梁，它使得我们可以通过分析导数的性质（一个局部、更简单的量）来推断原函数的性质（一个全局、更复杂的量）。

泰勒公式

泰勒公式是微积分中的一个核心定理，它提供了一种将复杂函数在某一点附近用一个多项式函数来近似表示的方法。如果一个函数足够光滑，即具有足够多阶的导数，我们就可以构建一个多项式，使其在指定点的值和各阶导数值都与原函数完全相同，从而实现高精度的局部近似。

设函数 f(x) 在点 x0​ 处具有直到 n 阶的导数，那么它的 n 阶泰勒多项式为：

Pn​(x)=k=0∑n​k!f(k)(x0​)​(x−x0​)k

这个多项式与原函数 f(x) 之间的差值被称为余项 Rn​(x)。根据余项形式的不同，泰勒公式主要有两种表达方式：

  1. 带有皮亚诺余项的形式：主要用于理论分析和极限计算，描述了当 x 无限趋近于 x0​ 时误差的性质。

    f(x)=k=0∑n​k!f(k)(x0​)​(x−x0​)k+o((x−x0​)n)

    这里的 o((x−x0​)n) 表示一个比 (x−x0​)n 更高阶的无穷小量。

  2. 带有拉格朗日余项的形式：给出了余项的一个精确表达式，可以用来估计近似的误差大小。

    f(x)=k=0∑n​k!f(k)(x0​)​(x−x0​)k+(n+1)!f(n+1)(ξ)​(x−x0​)n+1

    其中 ξ 是介于 x0​ 和 x 之间的某个点。这个形式在物理和工程计算中尤其有用。

特别地，当展开点 x0​=0 时，泰勒公式也被称为麦克劳林公式。

原理与推导： 泰勒公式的基本思想是寻找一个 n 次多项式 Pn​(x)=c0​+c1​(x−x0​)+⋯+cn​(x−x0​)n，使其在 x0​ 点的函数值及前 n 阶导数值与 f(x) 完全一致，即 Pn(k)​(x0​)=f(k)(x0​) 对 k=0,1,…,n 成立。

通过逐阶求导并令 x=x0​，可以依次确定多项式的系数：

  • k=0: Pn​(x0​)=c0​=f(x0​)
  • k=1: Pn′​(x0​)=c1​=f′(x0​)
  • k=2: Pn′′​(x0​)=2c2​=f′′(x0​)⟹c2​=2!f′′(x0​)​
  • …
  • k=n: Pn(n)​(x0​)=n!cn​=f(n)(x0​)⟹cn​=n!f(n)(x0​)​

这样就得到了泰勒多项式的系数公式 ck​=k!f(k)(x0​)​。而余项 Rn​(x)=f(x)−Pn​(x) 的具体形式则需要通过中值定理等更深入的工具来推导。

常见函数的麦克劳林公式

麦克劳林公式是泰勒公式在 x0​=0 处的特例，它将许多重要的初等函数展开成幂级数形式，是进行近似计算、求极限和理论分析的有力工具。以下是八个最常用函数的麦克劳林展开式。

1. 指数与对数函数

  • 指数函数 ex：其展开式形式简洁，系数为阶乘的倒数。 ex=1+x+2!x2​+3!x3​+4!x4​+⋯=n=0∑∞​n!xn​
  • 对数函数 ln(1+x)：系数为交错的自然数倒数。 ln(1+x)=x−2x2​+3x3​−4x4​+⋯=n=1∑∞​(−1)n−1nxn​

2. 三角函数

  • 正弦函数 sinx：作为奇函数，其展开式只包含 x 的奇次幂。 sinx=x−3!x3​+5!x5​−7!x7​+⋯=n=0∑∞​(−1)n(2n+1)!x2n+1​
  • 余弦函数 cosx：作为偶函数，其展开式只包含 x 的偶次幂。 cosx=1−2!x2​+4!x4​−6!x6​+⋯=n=0∑∞​(−1)n(2n)!x2n​
  • 正切函数 tanx：系数较为复杂，通常只记前几项。 tanx=x+3x3​+152x5​+o(x6)

3. 基于等比数列的函数

  • 1−x1​：这是公比为 x 的等比数列求和公式。 1−x1​=1+x+x2+x3+⋯=n=0∑∞​xn(∣x∣<1)
  • 1+x1​：由上式中的 x 替换为 −x 得到。 1+x1​=1−x+x2−x3+⋯=n=0∑∞​(−1)nxn(∣x∣<1)

4. 反三角函数

  • 反正切函数 arctanx：形式与 sinx 类似，但系数分母不是阶乘。 arctanx=x−3x3​+5x5​−7x7​+⋯=n=0∑∞​(−1)n2n+1x2n+1​

原理与推导： 这些公式之间存在紧密的联系，掌握其推导技巧有助于记忆。

  • 直接法：ex, sinx, cosx 的展开式可通过麦克劳林公式的定义，即 f(x)=∑n!f(n)(0)​xn，通过反复求导计算 f(n)(0) 得到。
  • 积分法：ln(1+x) 和 arctanx 的展开式可以通过对更简单的函数展开式进行逐项积分得到。
    • ln(1+x)=∫0x​1+t1​dt=∫0x​(1−t+t2−…)dt=x−2x2​+3x3​−…
    • arctanx=∫0x​1+t21​dt=∫0x​(1−t2+t4−…)dt=x−3x3​+5x5​−… 这种利用已知级数生成新级数的方法是幂级数应用中的一个核心技巧。

分部积分法

分部积分法是微积分中一项基本且重要的积分技巧，它能将一个不易直接求解的积分问题，转化为另一个相对更容易求解的积分与一个代数项的组合。这个方法本质上是函数乘积求导法则的逆运算。

其核心公式表达如下： ∫udv=uv−∫vdu 在使用此公式时，关键在于恰当地选择哪个部分作为 u（通常是容易求导的函数），哪个部分作为 dv（通常是容易积分的函数）。 反对幂指三，选u顺序

原理与推导： 该公式的推导过程非常直观，直接源于函数乘积的求导法则：

  1. 设有两个可微函数 u(x) 和 v(x)，它们的乘积的导数是：(uv)′=u′v+uv′。
  2. 对该等式两边同时求不定积分：∫(uv)′dx=∫u′vdx+∫uv′dx。
  3. 左边的积分 ∫(uv)′dx 结果就是 uv。
  4. 将 u′dx 记为 du，将 v′dx 记为 dv，代入上式得到：uv=∫vdu+∫udv。
  5. 移项整理，便得到了我们熟悉的分部积分公式。 技巧：

表格法 反对幂三指 前面的求导，后面的积分，交叉相乘，前面的符号为正负交错，最后+C 。 有理函数积分
